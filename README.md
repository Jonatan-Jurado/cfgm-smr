## 🎯 Sobre este proyecto

Este repositorio contiene mis apuntes personales del **CFGM en Sistemas Microinformáticos y Redes (SMR)** que estoy cursando en **ILERNA**. 

El objetivo es tener una base de conocimientos organizada, interconectada y accesible desde cualquier dispositivo, usando [Quartz](https://quartz.jzhao.xyz/) para convertir notas de Obsidian en una web estática.

## 📂 Estructura del proyecto
```
cfgm-smr/
├── content/                    # 📝 Contenido en Markdown
│   ├── CFGM/
│   │   ├── Glosario/          # 📖 +2000 términos técnicos
│   │   ├── Montaje/           # 🔧 Montaje y Mantenimiento
│   │   ├── Redes/             # 🌐 Redes Locales
│   │   ├── Sistemas/          # 💻 Sistemas Operativos
│   │   └── Ofimática/         # 📊 Aplicaciones Ofimáticas
│   └── index.md               # 🏠 Página principal
├── quartz/                     # ⚙️ Motor de Quartz
│   ├── components/            # Componentes personalizados
│   └── styles/                # Estilos SCSS
├── quartz.config.ts           # Configuración principal
└── quartz.layout.ts           # Layout de la web
```

## ✨ Características

- 🔗 **Glosario interconectado** — +2000 términos técnicos enlazados entre sí
- 🎨 **Tema Royal Velvet** — Diseño oscuro elegante con acentos púrpura
- 🔍 **Búsqueda integrada** — Encuentra cualquier concepto al instante
- 📱 **Responsive** — Funciona en móvil, tablet y escritorio
- 🌙 **Modo oscuro/claro** — Cambia según tu preferencia
- 📊 **Grafo de conocimiento** — Visualiza las conexiones entre conceptos

## 🚀 Desarrollo local
```bash
# Clonar el repositorio
git clone https://github.com/Jonatan-Jurado/cfgm-smr.git
cd cfgm-smr

# Instalar dependencias
npm ci

# Servidor de desarrollo
npx quartz build --serve

# Build de producción
npx quartz build
```
