### BLOCKCHAIN
**Blockchain**: es una tecnología de registro digital que permite a múltiples dispositivos compartir y acceder a una base de datos descentralizada de manera segura y transparente.

**CARACTERÍSTICAS:**
- *Descentralización:*
	- La info se almacena en una red distribuida de nodos
	- Cada nodo tiene una copia completa de la Base de Datos
	- Cada bloque de datos está enlazado de forma secuencial con el anterior y crea una cadena de bloques estables
- *Seguridad:*
	- Los nodos trabajan juntos para validar transacciones
	- Aseguran que todas las copias de la cadena sean consistentes y exactas
	- Se logra a través de algoritmos de consenso con reglas predefinidas que determinan como se alcanza y mantiene el consenso de la red
	- La criptografía se usa para proteger los datos y hace que solo las partes autorizadas puedan acceder a la información
- *Transparencia y Trazabilidad*:
	- Las transacciones son registradas de forma transparente y trazable
- *Inmutabilidad*:
	- Una vez un bloque de datos es agregado no se puede modificar ni eliminar sin el consentimiento de la mayoría de nodos
	- Garantiza la integridad de la info almacenada

**APLICACIONES:**
- Sector Bancario
- Almacenar info sensible
- Trazabilidad de Productos
- Rastreo y Verificación de Medicamentos
- Derechos de Autor y Distribución de Regalías

## SISTEMAS DIGITALIZADORES REALES
- **ERP (Gestión Empresarial)**
    - **Función:** Integra contabilidad, RRHH, inventario y ventas en una sola base de datos.
    - **Ejemplos:** SAP, Oracle ERP, Microsoft Dynamics.
- **CRM (Relaciones con Clientes)**
    - **Función:** Gestiona interacciones, seguimiento de ventas, marketing y soporte.
    - **Ejemplos:** Salesforce, HubSpot CRM, Zoho CRM.
- **ECM (Gestión de Contenido)**
    - **Función:** Captura, almacena y distribuye documentos y contenido corporativo.
    - **Ejemplos:** SharePoint, Alfresco, OpenText.
- **Automatización de Marketing**
    - **Función:** Automatiza envíos de emails, segmentación y seguimiento de campañas.
    - **Ejemplos:** HubSpot Marketing, Marketo, Mailchimp.
- **LMS (Gestión de Aprendizaje)**
    - **Función:** Administra cursos online, progreso del alumno y evaluaciones.
    - **Ejemplos:** Moodle, Canvas, Blackboard.
- **SCM (Cadena de Suministro)**
    - **Función:** Supervisa el flujo desde la materia prima hasta la entrega al cliente final.
    - **Ejemplos:** SAP SCM, Oracle SCM, Blue Yonder.
- **PMS (Gestión de Proyectos)**
    - **Función:** Planifica tareas, asigna recursos y gestiona presupuestos.
    - **Ejemplos:** Trello, Asana, Microsoft Project.
- **HRMS (Recursos Humanos)**
    - **Función:** Gestiona nóminas, reclutamiento y beneficios de los empleados.
    - **Ejemplos:** Workday, BambooHR, ADP.

## SISTEMAS DE ALMACENAMIENTO DE DATOS NO CONVENCIONALES

Ideales para datos **no estructurados**, escala masiva y procesamiento en tiempo real. Son altamente flexibles y escalables.
**TIPOS:**

- **En Columnas (Column-family)**
    - **Uso:** Consultas analíticas rápidas y _Business Intelligence_.
    - **Clave:** Almacena por columnas, no por filas.
    - **Ejemplos:** BigQuery, Redshift, HBase.
- **En Grafo**
    - **Uso:** Análisis de redes sociales, sistemas de recomendaciones y detección de fraudes.
    - **Clave:** Se basa en nodos (entidades) y aristas (relaciones).
    - **Ejemplos:** Neo4j, Amazon Neptune, Cosmos DB.
- **En Memoria (In-Memory)**
    - **Uso:** Máxima velocidad (trading, análisis financiero, anomalías).
    - **Clave:** Datos en RAM en lugar de disco.
    - **Ejemplos:** Redis, SAP HANA, Apache Ignite.
- **Distribuidos**
    - **Uso:** Big Data y aplicaciones en la nube a gran escala.
    - **Clave:** Datos repartidos en múltiples nodos (alta disponibilidad).
    - **Ejemplos:** Hadoop, Spark, Google Cloud Bigtable.



**EJEMPLOS**

- **MongoDB (Documental)**
    - **Perfil:** Orientada a documentos (JSON/BSON).
    - **Ventaja:** Muy flexible y popular en desarrollo ágil (Web, Apps móviles, IoT).
- **Apache Cassandra (Distribuida)**
    - **Perfil:** Diseñada para volúmenes masivos de datos.
    - **Ventaja:** Escalabilidad horizontal perfecta y alta disponibilidad (Redes sociales, Logs).
