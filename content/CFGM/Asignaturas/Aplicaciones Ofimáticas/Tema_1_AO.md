# Tema 1 - Instalación de Aplicaciones Ofimáticas

El mantenimiento de un equipo informático es necesario para conseguir un funcionamiento correcto y obtener el rendimiento esperado.

Este mantenimiento afecta tanto al **hardware** como al **software** e incluye tareas como:

- **Conexión y configuración:** preparar correctamente los dispositivos.
- **Actualización:** instalar las mejoras proporcionadas por los fabricantes.
- **Red:** mantener correctamente configuradas las conexiones.
- **Seguridad:** proteger la información y el funcionamiento del sistema.

---

## 1.1. ORGANIZACIÓN DE LOS SISTEMAS INFORMÁTICOS DE LA EMPRESA

### SISTEMA INFORMÁTICO

Un sistema informático es el conjunto de elementos necesarios para utilizar aplicaciones informáticas.

Está formado por tres elementos principales:

- **Hardware:** parte física y tangible del sistema.
- **Software:** programas e instrucciones utilizadas por el ordenador.
- **Usuarios:** personas que utilizan, crean o mantienen el sistema.


### APLICACIONES OFIMÁTICAS

Las aplicaciones ofimáticas son programas utilizados principalmente para realizar tareas propias de una oficina.
### TIPOS DE APLICACIONES OFIMÁTICAS

#### PROCESADORES DE TEXTO

- **Función:** crear y modificar documentos escritos.
- **Uso:** cartas, informes, documentos y otros textos.
- **Ejemplo del material:** Microsoft Word.

#### HOJAS DE CÁLCULO

- **Función:** trabajar con datos numéricos y realizar cálculos.
- **Uso:** gestión económica, cálculos, presupuestos, tablas, etc.
- **Ejemplo del material:** Microsoft Excel.

#### GESTORES DE BASES DE DATOS

- **Función:** almacenar y organizar grandes cantidades de información.
- **Ejemplo del material:** Microsoft Access.

#### PRESENTACIONES MULTIMEDIA

- **Función:** presentar productos, servicios o información de forma visual y dinámica.
- **Ejemplo del material:** Microsoft PowerPoint.

#### SOFTWARE DE IMAGEN, VÍDEO Y SONIDO

- **Imagen:** permite editar imágenes. Ejemplo: Photoshop.
- **Vídeo:** permite editar y crear vídeos. Ejemplo: Premiere.
- **Sonido:** permite trabajar con audio. Ejemplo: Audacity.

### SOFTWARE OFIMÁTICO EN LA NUBE

Las aplicaciones ofimáticas también pueden funcionar mediante Internet.

- **Aplicación en la nube:** permite trabajar sobre documentos desde diferentes equipos.
- **Colaboración:** varios dispositivos pueden acceder al mismo documento.
- **Ejemplos del material:** Zoho y Google Docs.


### ELEMENTOS DE UN EQUIPO INFORMÁTICO

El hardware puede dividirse principalmente en:

1. **Componentes internos:** necesarios para que el ordenador funcione.
2. **Periféricos:** permiten interactuar con el ordenador o ampliar sus funciones.


### COMPONENTES INTERNOS

#### PROCESADOR

- **Central Processing Unit (CPU), unidad central de proceso:** componente encargado del procesamiento de información.
- **Importancia:** el material lo considera uno de los componentes fundamentales del equipo.
- **Velocidad:** puede expresarse en gigahercios (GHz).

#### MEMORIA RAM

- **Random Access Memory (RAM):** memoria reutilizable donde se cargan los programas cuando están en ejecución.
- **Multitarea:** puede contener varios programas en ejecución simultáneamente.
- **Capacidad:** una mayor cantidad de RAM permite disponer de más espacio para programas y datos en uso.
- **Volatilidad:** su contenido desaparece al apagar el ordenador.

#### MEMORIA ROM

- **Read Only Memory (ROM):** memoria cuyo contenido no desaparece al apagar el equipo.
- **Función indicada en el material:** contiene instrucciones necesarias para comenzar la puesta en marcha del ordenador.
- **Uso:** no se utiliza como almacenamiento habitual de documentos o aplicaciones.

#### PLACA BASE

- **Placa base o motherboard:** circuito principal al que se conectan los diferentes componentes del ordenador.
- **Conexiones:** procesador, memoria, discos, tarjeta gráfica y diferentes puertos.

#### FUENTE DE ALIMENTACIÓN

- **Fuente de alimentación:** proporciona energía eléctrica a los componentes internos.
- **Conectores:** dispone de diferentes salidas para alimentar distintos dispositivos.
- **Fallo:** si deja de funcionar, el ordenador no puede encenderse correctamente.

#### ALMACENAMIENTO

- **Hard Disk Drive (HDD):** sistema de almacenamiento donde pueden encontrarse el sistema operativo, controladores, programas y datos del usuario.
- **Capacidad:** suele expresarse en gigabytes (GB) o terabytes (TB).
- **Disco de estado sólido (SSD):** tecnología de almacenamiento con tiempos de acceso menores que los discos tradicionales.

#### UNIDADES ÓPTICAS

- **Compact Disc (CD):** medio óptico de almacenamiento.
- **Digital Versatile Disc (DVD):** medio óptico con mayor capacidad que un CD.
- **Blu-ray Disc (BD):** otro medio óptico de almacenamiento.

#### DISIPADOR Y VENTILADOR

- **Disipador:** absorbe y distribuye el calor producido por componentes como la CPU.
- **Ventilador:** ayuda a evacuar el calor del disipador.
- **Objetivo:** mantener una temperatura adecuada de funcionamiento.

#### TARJETA GRÁFICA

- **Tarjeta gráfica:** transforma los datos necesarios para generar la información visual mostrada al usuario.
### PERIFÉRICOS

Los periféricos permiten utilizar las diferentes funciones del ordenador.

#### MONITOR

- **Monitor:** muestra al usuario la información generada por el ordenador.
- **Resolución:** cantidad de píxeles utilizados para formar la imagen.
- **Píxel:** unidad mínima de representación gráfica.

#### TECLADO Y RATÓN

- **Teclado:** periférico utilizado principalmente para introducir texto y órdenes.
- **Ratón:** periférico utilizado para controlar el cursor y seleccionar elementos.
- **Con cable:** conexión física directa.
- **Inalámbricos:** utilizan ondas y necesitan una fuente de alimentación propia.

#### ESCÁNER

- **Escáner:** convierte documentos físicos en información digital.

#### IMPRESORA

- **Impresora:** convierte información digital en documentos físicos.

#### CÁMARA WEB

- **Cámara web:** captura imágenes o vídeo mediante una cámara conectada al equipo.
- **Uso:** puede utilizarse para comunicaciones o emisiones en línea.

#### TABLETA GRÁFICA

- **Tableta gráfica:** permite controlar el cursor mediante un lápiz.
- **Uso habitual:** tratamiento y creación de imágenes.

#### SOFTWARE DE SISTEMA

- **Software de sistema:** administra el hardware y las funciones básicas del ordenador.
- **Principal ejemplo:** sistema operativo.
- **Ejemplo del material:** Windows.

#### SOFTWARE DE APLICACIÓN

- **Software de aplicación:** permite al usuario realizar tareas concretas.
- **Ejemplos:** escribir documentos, realizar cálculos o reproducir vídeos.
- **Ejemplo del material:** Microsoft Word.

#### SOFTWARE DE PROGRAMACIÓN

- **Software de programación:** herramientas utilizadas para crear programas.
- **Ejemplo del material:** Eclipse.


### LICENCIAS DE SOFTWARE

#### SOFTWARE LIBRE

- **Software libre:** proporciona determinadas libertades sobre el uso y modificación del programa.
- **Código fuente:** se distribuye junto al programa según la explicación del material.
- **Uso:** puede utilizarse para diferentes propósitos.
- **Estudio:** permite analizar cómo funciona.
- **Modificación:** puede adaptarse a otras necesidades.
- **Distribución:** permite distribuir copias.
- **Mejora:** permite modificarlo y compartir las mejoras.

#### SOFTWARE PROPIETARIO

- **Software propietario o privado:** limita determinadas posibilidades de uso, modificación o distribución.
- **Código fuente:** no está disponible para el usuario.
- **Modificación:** depende del propietario o desarrollador.

#### SOFTWARE DE FUENTE ABIERTA

- **Software de fuente abierta:** permite acceder al código y realizar determinadas modificaciones y distribuciones siguiendo las condiciones de su licencia.

#### SOFTWARE DE DOMINIO PÚBLICO

- **Software de dominio público:** software de uso libre cuyos derechos son públicos según la clasificación utilizada en el tema.


### OTROS TIPOS DE LICENCIAS

- **Copyleft:** debe mantenerse la referencia al autor según el material.
- **Semilibre:** permite determinadas operaciones siempre que no exista ánimo de lucro.
- **Freeware:** permite distribución gratuita, pero no modificación.
- **Shareware:** distribución gratuita con limitaciones funcionales o temporales.
- **Educativa:** destinada a centros educativos y puede incluir limitaciones.



### INSTALACIÓN Y DESINSTALACIÓN DE PROGRAMAS

La instalación es el proceso mediante el cual se crean en el ordenador los archivos y carpetas necesarios para utilizar un programa.

Antes de instalar debemos comprobar:

- **Versión:** qué versión queremos instalar.
- **Versiones anteriores:** el material recomienda eliminarlas antes de instalar una nueva.
- **Compatibilidad:** comprobar que el equipo cumple los requisitos.
- **Sistema operativo:** verificar que sea compatible con la aplicación.

### REQUISITOS DE INSTALACIÓN

Los programas pueden exigir determinadas características mínimas:

- **RAM:** cantidad mínima de memoria.
- **Procesador:** capacidad necesaria.
- **Disco:** espacio libre disponible.
- **Gráficos:** tarjeta o recursos gráficos necesarios.
- **Sistema operativo:** versión compatible.
- **Usuarios:** posibilidad de trabajar con uno o varios usuarios.

En Windows, el material indica que puede consultarse información del equipo mediante:

`Equipo > Propiedades`

o mediante:

`Panel de control > Sistema > Mantenimiento sistema`

### PROCESO GENERAL DE INSTALACIÓN

1. **Obtener el programa:** descargarlo o utilizar un CD/DVD.
2. **Licencia:** introducir la clave cuando sea necesaria.
3. **Ruta:** elegir dónde se instalará.
4. **Componentes:** seleccionar los elementos adicionales que queramos instalar.
5. **Reinicio:** reiniciar cuando sea necesario para aplicar los cambios.


### ACTUALIZACIÓN DEL SOFTWARE

- **Actualización:** revisión o paquete que corrige errores o incorpora nuevas funcionalidades.
- **Objetivo:** mantener el programa adaptado a nuevas necesidades y solucionar problemas.
- **Automatización:** los sistemas operativos pueden buscar, descargar e instalar actualizaciones automáticamente.
- **Windows Update:** servicio mencionado en el material para actualizar software en Windows.
- **App Store:** sistema utilizado para determinadas actualizaciones en macOS según el tema.


### NECESIDADES DEL ENTORNO DE TRABAJO

No siempre debemos instalar todos los programas disponibles.

Hay que seleccionar las aplicaciones según las necesidades reales para:

- Ahorrar espacio.
- Evitar software innecesario.
- Reducir costes cuando existen licencias de pago.

#### TRABAJO DE OFICINA BÁSICO

Como mínimo puede necesitar:

- Procesador de textos.
- Presentaciones.
- Hoja de cálculo.

#### GESTIÓN DE DATOS

Para grandes cantidades de información puede necesitar:

- Gestor de bases de datos.

#### TRATAMIENTO AUDIOVISUAL

Puede necesitar programas para:

- Imágenes.
- Vídeo.
- Sonido.

### CONFIGURACIÓN Y ADAPTACIÓN DEL SOFTWARE

Aunque un software propietario no permita modificar directamente su código, puede ofrecer opciones de personalización.

#### BARRA DE HERRAMIENTAS

- **Personalización:** permite elegir qué herramientas aparecen visibles.
- **Acceso directo:** facilita el acceso a las funciones más utilizadas.

#### PLANTILLAS Y ESTILOS

- **Plantilla:** estructura previamente preparada para crear documentos.
- **Estilos:** permiten mantener un diseño común.
- **Objetivo empresarial:** unificar el aspecto de los documentos.

### COMPLEMENTOS

- **Complemento:** funcionalidad adicional que incorpora nuevas órdenes o características a una aplicación.
- **Objetivo:** ampliar las posibilidades del programa y mejorar la productividad.
- **Instalación:** algunos se instalan con el programa y otros pueden añadirse posteriormente.


### DIAGNÓSTICO Y RESOLUCIÓN DE PROBLEMAS

Muchos problemas ofimáticos están relacionados con:

1. Versiones del software.
2. Formatos de archivo.

#### COMPATIBILIDAD ENTRE VERSIONES

Las versiones nuevas suelen poder trabajar con archivos creados por versiones anteriores, pero una versión antigua puede no reconocer formatos creados posteriormente.

El material utiliza como ejemplo:

- **`.doc`:** formato utilizado por versiones antiguas de Word.
- **`.docx`:** formato utilizado por versiones posteriores.


> [!important] Importante
> Al guardar en un formato antiguo puede producirse **pérdida de características** que la versión anterior no soporta.

#### COMPATIBILIDAD ENTRE FORMATOS

Cuando diferentes aplicaciones utilizan formatos distintos puede ser necesario:

- **Importar:** incorporar información desde otro formato.
- **Exportar:** guardar la información en otro formato.

Los formatos sencillos suelen mantener mejor la información.

Elementos avanzados como:

- Degradados.
- Efectos artísticos.
- Tablas personalizadas.
- Complementos específicos.

pueden perderse o modificarse durante una conversión.

### OPTIMIZACIÓN DEL ALMACENAMIENTO

Una forma de aumentar el espacio disponible es utilizar dispositivos adicionales.

El material recomienda como posibilidad:

- **SSD interno:** sistema operativo y programas importantes.
- **HDD interno:** información menos crítica.
- **Disco externo:** fotografías, documentos, vídeos u otros archivos.

### MEDIDAS PARA AHORRAR ESPACIO

- **Archivos grandes:** trasladarlos a almacenamiento externo cuando sea adecuado.
- **Archivos antiguos:** mover los que lleven mucho tiempo sin utilizarse.
- **Duplicados:** eliminar copias innecesarias.
- **Programas:** desinstalar aplicaciones que no se utilicen.
- **Copias de seguridad:** eliminar las antiguas cuando ya no sean necesarias.
- **Papelera:** vaciarla periódicamente.
- **Archivos temporales:** eliminarlos cuando sea posible.
- **Usuarios innecesarios:** evitar cuentas que no vayan a utilizarse.


## 1.2. DOCUMENTACIÓN DE INCIDENCIAS Y RESOLUCIÓN DE PROBLEMAS

Los sistemas informáticos necesitan mantenimiento para prevenir y resolver posibles incidencias.

### GESTIÓN DE INCIDENCIAS

- **Incidencia:** problema que afecta al funcionamiento normal del sistema.
- **Mantenimiento:** ayuda a prevenir y resolver averías.
- **Asistencia remota:** permite atender problemas mediante medios electrónicos, telefónicos o telemáticos.

### CENTRO DE ATENCIÓN AL USUARIO

- **Centro de Atención al Usuario (CAU):** servicio encargado de organizar y atender consultas e incidencias de los usuarios.
- **Herramientas:** puede utilizar recursos físicos y lógicos para gestionar las solicitudes.

### PROTOCOLO DE RESOLUCIÓN

El proceso indicado en el tema consta de cuatro fases:

1. **Recepción y documentación:** registrar la incidencia.
2. **Asignación:** determinar quién debe resolverla.
3. **Resolución:** solucionar el problema.
4. **Cierre:** finalizar y dejar constancia de la solución.

> [!important] Pasos
> ### PROCESO DE UNA INCIDENCIA
>
> **Recepción → asignación → resolución → cierre**


### INVENTARIOS

- **Inventario:** recopilación organizada de información sobre hardware y software.
- **Compatibilidad:** ayuda a comprobar si una nueva aplicación puede instalarse.
- **Mantenimiento:** permite conocer qué componentes existen antes de realizar cambios.
- **Soporte:** puede realizarse mediante documentos, hojas de cálculo o bases de datos.
- **Herramientas mencionadas:** Everest! y Aida64.


### REGISTRO DE INCIDENCIAS

Las incidencias deben almacenarse en un registro.

Este registro puede incluir:

- **Tipo y número:** clasificación e identificador.
- **Fecha y hora:** momento en que aparece.
- **Persona:** quién la comunica.
- **Técnicos:** quiénes están asignados.
- **Descripción:** qué problema existe.
- **Medidas correctoras:** acciones realizadas.
- **Estado:** pendiente, asignada, resuelta, etc.


## 1.3. SISTEMAS OPERATIVOS: TIPOS, PERMISOS, USUARIOS Y CONFIGURACIÓN

### SISTEMA OPERATIVO

- **Sistema operativo:** software encargado de poner en funcionamiento el ordenador y actuar como intermediario entre usuario y hardware.

Sus funciones principales son:

- **Hardware:** controlar los componentes físicos.
- **Almacenamiento:** gestionar los datos.
- **Aplicaciones:** controlar su ejecución.
- **Configuración:** configurar componentes.
- **Comunicación:** permitir la comunicación con otros ordenadores.
- **Procesos y recursos:** administrarlos.
- **Errores:** intervenir en su recuperación.


### SEGÚN EL NÚMERO DE PROCESOS

#### MONOTAREA

- **Monotarea:** mantiene un único proceso en ejecución.
- **Funcionamiento:** realiza las tareas secuencialmente.

#### MULTITAREA

- **Multitarea:** permite ejecutar varios procesos simultáneamente.


### SEGÚN EL NÚMERO DE USUARIOS

#### MONOUSUARIO

- **Monousuario:** permite trabajar a un único usuario.
- **Ejemplo indicado:** antiguo DOS.

#### MULTIUSUARIO

- **Multiusuario:** permite trabajar a varios usuarios.


### SISTEMAS OPERATIVOS MENCIONADOS

#### DOS

- **Disk Operating System (DOS):** sistema operativo de disco.
- **MS-DOS:** versión creada por Microsoft.
- **Interfaz:** no utiliza un entorno gráfico como los sistemas actuales.
- **Uso:** actualmente prácticamente desaparecido según el material.

#### WINDOWS

- **Windows:** sistema operativo propietario de Microsoft.
- **Interfaz:** entorno gráfico.
- **Uso:** ampliamente utilizado en entornos domésticos y empresariales.

#### OS/2

- **OS/2:** sistema operativo creado por International Business Machines (IBM).
- **Aplicaciones:** el material destaca que dispone de pocas aplicaciones.

#### MAC OS

- **Mac OS:** sistema operativo utilizado en ordenadores Macintosh.
- **Fabricante:** Apple.

#### LINUX

- **Linux:** sistema operativo gratuito descrito en el material como clon de Unix.
- **Comunidad:** su desarrollo y mantenimiento cuenta con participación comunitaria.
- **Distribuciones:** Ubuntu, Debian y Fedora.
- **Red:** dispone de herramientas avanzadas de administración y seguridad.


### TIPOS DE USUARIOS Y PERMISOS

#### ADMINISTRADOR

- **Administrador:** usuario con control total del sistema.
- **Usuarios:** puede crear y eliminar cuentas.
- **Permisos:** puede asignarlos o retirarlos.
- **Software:** puede instalar y desinstalar programas.

#### USUARIO LOCAL

- **Usuario local:** tiene determinados permisos limitados.
- **Objetivo:** evitar modificaciones que puedan alterar o dañar el sistema.

#### INVITADO

- **Invitado:** dispone de permisos muy restringidos.
- **Configuración:** no puede modificar el equipo.


## 1.4. MANUALES TÉCNICOS, PROTOCOLOS Y REPORTES

### MANUALES DE USO

- **Manual de uso:** explica las posibilidades del software y puede ofrecer soluciones a incidencias habituales.
- **Fabricante:** proporciona información específica del producto.
- **Internet:** también puede utilizarse para buscar soluciones, aunque el material recomienda comprobar la fiabilidad de la fuente.


### PROTOCOLOS DE ACTUACIÓN

- **Protocolo:** conjunto de pasos establecidos para intentar resolver una incidencia.
- **Objetivo:** permitir actuar incluso cuando el usuario no tiene experiencia suficiente.
- **Escalado:** si el problema no se resuelve, debe contactarse con el servicio técnico.

### REPORTES AL SERVICIO TÉCNICO

- **Reporte:** informe que contiene información sobre un error y el entorno en el que ocurrió.
- **Objetivo:** ayudar a los técnicos a identificar problemas.
- **Actualizaciones:** la información puede ayudar a corregir fallos en futuras versiones.
- **Envío:** según el material, es voluntario.


## 1.5. EMPRESAS DE PRESTACIÓN DE SERVICIOS INFORMÁTICOS

El material diferencia las empresas según el tipo de servicio que proporcionan.

### EMPRESAS DE INTERNET

- **Servicios:** alojamiento web, dominios, contenidos, foros, comercio electrónico, buscadores y servidores para videojuegos.

### EMPRESAS DE SOFTWARE

- **Función:** desarrollar y mantener programas.
- **Diseño:** también pueden realizar trabajos gráficos como logotipos, maquetas web o infografías.

### EMPRESAS MULTIMEDIA

- **Función:** creación de contenidos que requieren interacción.
- **Ejemplos:** catálogos interactivos o presentaciones multimedia.


### CENTRALIZACIÓN DE LOS SERVICIOS

#### EMPRESAS CENTRALIZADAS

- **Centralizadas:** ofrecen varios servicios desde un mismo panel o lugar de gestión.

> [!example] Ejemplo
> Desde un único panel podemos gestionar:
>
> - Alojamiento web.
> - Dominios.
> - Contenidos.

#### EMPRESAS DESCENTRALIZADAS

- **Descentralizadas:** ofrecen diferentes servicios, pero se gestionan desde lugares o páginas diferentes.


### GARANTÍAS

Según los periodos indicados específicamente en el material:

- **Productos:** margen de dos años.
- **Servicios:** margen de tres meses.


La garantía exige además determinar si el fallo corresponde al producto o si ha sido provocado por un uso incorrecto.

Los términos y condiciones deben aparecer especificados en la garantía correspondiente.
