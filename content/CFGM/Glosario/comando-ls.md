# Comando ls
Comando utilizado para listar el contenido de un directorio.
- _Parámetro -l_: muestra el contenido en modo lista, incluyendo permisos, número de i-nodos, usuario propietario, grupo propietario, fecha y hora de creación y nombre del fichero o directorio.
- _Parámetro -a_: muestra también los archivos ocultos.
