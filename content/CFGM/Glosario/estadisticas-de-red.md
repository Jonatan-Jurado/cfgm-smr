# Estadísticas de red
Conjunto de datos que presentan el estado de todas las conexiones registradas en el sistema e indican aquellas que permanecen activas.
Existen herramientas, tanto de código abierto como propietarias, que ofrecen un mayor catálogo de opciones y mejoras en la interfaz gráfica para recoger estas estadísticas del sistema.
