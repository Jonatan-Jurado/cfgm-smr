# Ruta relativa

Es el tipo de [[Ruta]] que señala la ubicación de un fichero o [[Directorio]] tomando como punto de referencia el Directorio actual en el que se encuentra trabajando el [[Usuario]], en lugar de partir desde el Directorio raíz|Directorio raíz]].
