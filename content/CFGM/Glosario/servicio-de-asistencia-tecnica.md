# Servicio de Asistencia Técnica
Es un departamento de una empresa dedicada al mantenimiento que se encarga de solucionar las averías.
- _Modalidades de solución de averías_:
    - _Telefónicamente_: Un técnico indica al usuario los pasos a seguir para solucionar el problema.
    - _Control remoto_: El técnico se conecta remotamente al equipo averiado del usuario a través de internet para manipularlo sin necesidad de desplazarse.
    - _Presencialmente (in situ)_: Cuando las vías anteriores no son suficientes, el técnico se desplaza al lugar del fallo para solucionarlo.
