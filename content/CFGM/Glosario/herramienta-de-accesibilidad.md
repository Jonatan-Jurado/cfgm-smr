# Herramienta de accesibilidad

Conjunto de utilidades y configuraciones integradas en [[El Sistema operativo]]|el Sistema operativo para permitir el uso del equipo a personas con discapacidades. Incluye lectores de pantalla y magnificadores como [[Orca]], controles específicos para la velocidad del ratón, funciones de repetición de teclas para movilidad reducida, ajustes de alto contraste o brillo, y sistemas de gestión de órdenes mediante comandos de voz.
