# Sensor
Un sensor es un dispositivo capaz de detectar cambios en el entorno y convertir estas variaciones en señales que pueden ser interpretadas por un sistema ciberfísico (CPS).

Existen diversos tipos de sensores para captar distintas magnitudes:
- _temperatura_
- _humedad_
- _presión_
- _velocidad_
- _posición_
- _luz_
