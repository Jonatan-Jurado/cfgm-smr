# Conversión octal-hexadecimal

Procedimiento de conversión indirecta que requiere el uso del [[Sistema binario]] como paso intermedio. Para pasar de octal a hexadecimal, primero se transforma cada dígito octal a ternas de bits (binario) y, posteriormente, se reagrupan esos bits en conjuntos de cuatro para obtener los caracteres hexadecimales correspondientes. El mismo método se aplica de forma inversa para pasar de hexadecimal a octal.
