# Minimización de desechos
Proceso de diseño de productos para que sean duraderos, reparables y reciclables (conocido como «ecodiseño»), con el fin de reducir la cantidad de desechos generados. Esta práctica de economía circular promueve que los productos y materiales se utilicen durante el mayor tiempo posible.
