# Máquina virtual de proceso
Herramientas que solo permiten virtualizar un único proceso. No se instala ningún sistema operativo, simplemente se aísla su aplicación.

Este tipo de máquinas virtuales se crean cuando se lanza la aplicación y se cierran cuando finalizan. Durante su ejecución, sí que requiere de los recursos de la máquina física para poder funcionar. Se utiliza para crear aplicaciones independientes del sistema operativo, como es el caso de JVM, la máquina virtual de Java.
