# Superusuario

Es el [[Usuario]] especial del sistema (identificado como `root`) que posee privilegios totales para realizar cualquier tarea de administración, como la gestión de usuarios, grupos o la instalación de [[Software]]. En las distribuciones modernas de Linux, el acceso a estas funciones se realiza habitualmente mediante el comando `sudo`, que permite a un Usuario autorizado ejecutar órdenes con los privilegios del superusuario de forma temporal.
