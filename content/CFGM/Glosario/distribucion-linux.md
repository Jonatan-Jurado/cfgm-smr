# Distribución Linux
Conjunto de paquetes software basados en el núcleo Linux.
- _Elección_: Para elegir una, es necesario comparar características como la estabilidad, el administrador de paquetes y la interfaz gráfica de usuario (GUI) para seleccionar la que mejor se adapte a las necesidades del usuario.
- _Ejemplo_: Ubuntu es una distribución basada en Debian que mejora la interfaz gráfica, haciéndola más intuitiva y fácil de usar, y cuyo entorno de escritorio es GNOME.
