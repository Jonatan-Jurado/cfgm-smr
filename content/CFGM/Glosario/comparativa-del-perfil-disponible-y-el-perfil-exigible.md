# Comparativa del perfil disponible y el perfil exigible
Proceso para realizar una evaluación efectiva entre las competencias, habilidades y conocimientos que un individuo posee (perfil disponible) y los que son requeridos para un puesto o programa (perfil exigible). Es útil seguir estos pasos:
- _Identificación de competencias clave_:
    - _Perfil exigible_: revisar el plan de estudios y los objetivos del programa académico para identificar las competencias clave que se deben adquirir.
    - _Perfil disponible_: realizar un autoanálisis para identificar las competencias que ya se poseen.
- _Evaluación de habilidades y conocimientos_:
    - _Perfil exigible_: listar las habilidades técnicas y conocimientos específicos requeridos por el título.
    - _Perfil disponible_: evaluar las habilidades y conocimientos actuales mediante autoevaluaciones, feedback de colegas y supervisores, y revisiones de desempeño.
- _Identificación de brechas_: comparar las competencias, habilidades y conocimientos del perfil disponible con los del perfil exigible para identificar las áreas donde existen brechas.
- _Plan de acción_: desarrollar un plan de acción para cerrar las brechas identificadas. Esto puede incluir cursos adicionales, certificaciones, prácticas profesionales, y desarrollo de habilidades blandas.
