# Licencia RETAIL
Tipo de licencia de Windows cuyas características principales son:
- _Componentes_: Se compone de una etiqueta con el holograma de Windows y un DVD para la instalación.
- _Uso_: A diferencia de las licencias OEM, esta permite ser instalada en diferentes máquinas, con la única condición de que los equipos no se estén usando a la vez.
- _Modificación de hardware_: Permite realizar cualquier tipo de modificación de hardware; en tal caso, se debe desactivar y activar la licencia de nuevo.
- _Virtualización_: Permite la virtualización, aunque se requiere una licencia por cada máquina virtual con este sistema operativo.
