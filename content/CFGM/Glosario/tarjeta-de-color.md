# Tarjeta de Color
Un sistema de clasificación visual utilizado en el proceso de triaje, donde se coloca una tarjeta de color unida al cuerpo de cada víctima. Esta tarjeta indica la prioridad de la atención que requiere el afectado.

*   _Rojo (Prioridad I)_: Se utiliza para víctimas graves, pero recuperables. Deben ser los primeros en ser atendidos. Ejemplos incluyen heridas muy graves o personas con parada cardiorrespiratoria presenciada.
*   _Amarillo (Prioridad II)_: Se emplea para víctimas graves pero estables, que pueden esperar un tiempo antes de ser evacuadas. Corresponde a casos como heridas abiertas que puedan requerir puntos (sin afectar órganos vitales) o la presencia de un cuerpo extraño en el ojo.
*   _Verde (Prioridad III)_: Se utiliza para víctimas leves, no urgentes, que no requieren atención hospitalaria inmediata. Pertenecen a esta categoría ejemplos como contusiones, esguinces o fracturas cerradas de huesos largos.
*   _Negro (Prioridad IIII)_: Estas víctimas no requieren atención inmediata, ya que son personas ya fallecidas o con muy pocas posibilidades de supervivencia. Son ejemplos un traumatismo craneoencefálico con salida de masa encefálica o un fallo multiorgánico.
