# VirtualBox
Software para la creación de máquinas virtuales, perteneciente a Oracle.

Su versión actual es la 5.1, una de las más conocidas y de uso más extendido globalmente. Cuenta con licencias gratuitas (para uso personal) y privativas (Oracle VM VirtualBox). Ofrece una gran cantidad de sistemas operativos sobre los que podemos instalar este software (hosts): GNU/Linux, MAC OS X, OS/2, Solaris/OpenSolaris y Windows. Una vez instalado, permite virtualizar (guests) GNU/Linux, FreeBSD, OpenBSD, entre otros.
