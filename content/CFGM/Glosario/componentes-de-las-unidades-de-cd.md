# Componentes de las Unidades de CD
Dispositivos diseñados para [[Operaciones]] de lectura y escritura sobre compact discs. Sus componentes internos principales son:
* **Cabeza lectora:** Compuesta por un haz láser.
* **Motor de la cabeza:** Acciona el movimiento del láser.
* **Motor de rotación:** Hace girar el disco.
* **Mecanismo de carga:** Bandeja de plástico para introducir el soporte.
