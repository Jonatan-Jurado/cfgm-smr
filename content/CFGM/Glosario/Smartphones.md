# Smartphones
Dispositivos híbridos que combinan las capacidades de un teléfono móvil con las funciones de una PDA y conectividad permanente a [[Internet]]. Se gestionan mediante un [[Sistema Operativo]] que permite la instalación de aplicaciones, convirtiéndolos en herramientas multifuncionales esenciales para la comunicación y el procesamiento de datos personales.
