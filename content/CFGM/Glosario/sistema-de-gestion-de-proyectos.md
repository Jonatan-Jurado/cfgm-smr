# Sistema de gestión de proyectos
Estos sistemas ayudan a planificar, organizar, asignar recursos, seguir el progreso y gestionar el presupuesto de proyectos.
Algunos ejemplos incluyen:
- _Trello_
- _Asana_
- _Microsoft Project_
