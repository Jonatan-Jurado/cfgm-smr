# Prioridad de arranque

Configuración establecida dentro de la BIOS o UEFI de un equipo que determina el orden de búsqueda de un sistema operativo en los diferentes dispositivos de almacenamiento. El técnico puede modificar esta jerarquía en el apartado denominado habitualmente "BOOT" para permitir que el ordenador inicie desde una unidad óptica (CD-ROM), una memoria USB o el disco duro interno, facilitando así tareas de instalación o reparación del sistema.
