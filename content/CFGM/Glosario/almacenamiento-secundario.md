# Almacenamiento Secundario
Sistema de almacenamiento de datos diseñado para perdurar en el tiempo, a diferencia de la memoria RAM, que es volátil y de baja capacidad. Este tipo de memoria conserva los datos incluso después de apagar el equipo, a menos que el usuario los borre explícitamente.

Características principales:
- _Costo_: Son más económicos que las memorias RAM.
- _Capacidad_: Ofrecen una capacidad de almacenamiento significativamente mayor que las memorias RAM.
- _Almacenamiento_: Es permanente.
- _Velocidad_: Son más lentos en comparación con las memorias RAM.
- _Conexión_: Generalmente son dispositivos internos que se conectan a la placa base a través de un bus de datos.

Según la tecnología utilizada para almacenar los datos, se pueden distinguir entre discos magnéticos, ópticos, electrónicos e híbridos.
