# Modding
El modding es una expresión coloquial de la palabra inglesa "modify" (modificar), que hace referencia al acto de cambiar tanto el aspecto exterior como el interior de un ordenador. Esto se realiza con el fin de ampliar las características de cualquier componente interno o para personalizar su aspecto con una imagen diferente.

Las modificaciones que se pueden realizar en un equipo informático incluyen:
-   _Hacer transparente el interior de la caja_: con la colocación de una tapa transparente y luminosa.
-   _Personalizar el interior y el exterior_: con luces y colores llamativos.
-   _Colocación de ventiladores adicionales_: para favorecer la refrigeración.
-   _Ampliación de monitores_: para mejorar la visualización de los datos.
-   _Instalación de sensores_: para controlar la temperatura interna.
-   _Instalación de sistemas de refrigeración_.

Para realizar manualmente estos cambios, se necesitan herramientas específicas como:
-   _Dremel_: una herramienta giratoria multifunción utilizada para taladrar, cortar, lijar, grabar, entre otras funciones.
-   _Sierra caladora_
-   _Destornillador_
-   _Alicates_
-   _Soldador_

También existe la opción de adquirir piezas ya modificadas y simplemente reemplazarlas.
