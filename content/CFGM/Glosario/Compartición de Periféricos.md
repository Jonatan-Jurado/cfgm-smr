# Compartición de Periféricos
Capacidad de los sistemas de virtualización para permitir que la máquina virtual acceda a dispositivos de hardware conectados al equipo físico. Esto incluye memorias USB, teclados, ratones, unidades de CD/DVD, entre otros. Gracias a esta funcionalidad, el usuario puede emplear el mismo dispositivo de forma indistinta tanto en el sistema anfitrión como en el invitado, previa configuración en el software de virtualización.
