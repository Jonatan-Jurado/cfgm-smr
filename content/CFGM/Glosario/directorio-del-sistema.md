# Directorio del sistema

Ubicaciones predefinidas y críticas en la estructura de [[Windows]] donde se almacenan componentes esenciales del [[Sistema operativo]]:
- **\Boot**: Archivos críticos para el arranque del sistema.
- **\Archivos de programas**: Binarios y librerías de las aplicaciones instaladas.
- **\ProgramData**: Carpeta oculta para datos compartidos de aplicaciones, configuración del menú Inicio y herramientas administrativas.
- **\PerfLogs**: Registros (logs) sobre el rendimiento y eventos de las aplicaciones.
- **\Usuarios**: Contiene los perfiles personales y datos específicos de cada [[Usuario]] del sistema.
