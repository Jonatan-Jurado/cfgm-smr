# Mac OS
Sistema operativo lanzado en 1984 y desarrollado por Apple Inc. Fue el primer sistema operativo con una interfaz gráfica de usuario (GUI) que se creó con éxito. Otra de sus innovaciones fue la incorporación de un ratón, para evitar el uso de la línea de comandos.
