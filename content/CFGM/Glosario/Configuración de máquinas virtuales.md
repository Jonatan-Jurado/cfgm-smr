# Configuración de máquinas virtuales
Proceso de ajuste de los parámetros de una máquina virtual existente, especialmente para la instalación o modificación del sistema operativo. Se accede a esta opción a través de "Edit virtual machine settings", donde se pueden editar los parámetros configurados durante la creación, como la RAM o el espacio de disco duro.
