# Herramienta de información del sistema

Son aplicaciones o comandos diseñados para recopilar y visualizar los datos técnicos del [[Hardware]] y [[Software]]|Hardware y Software de un equipo. En sistemas Linux, existen comandos básicos como `df -h` para consultar el espacio en disco, pero también Software externo con [[Interfaz]] gráfica como `hardinfo` y `sysinfo`. Estas herramientas permiten obtener una visión global de las configuraciones del sistema, facilitando las tareas de inventariado y diagnóstico.
