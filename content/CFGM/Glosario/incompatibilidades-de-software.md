# Incompatibilidades de software
Ocurren cuando un dispositivo está correctamente conectado, pero su driver no es soportado por el sistema operativo en cuestión.
- _Soluciones para este tipo de incidencias_:
    - Descargar un nuevo controlador desde la página del fabricante.
    - Sopesar el cambio de sistema operativo si se sospecha que el incidente podría repetirse con otros dispositivos futuros.
