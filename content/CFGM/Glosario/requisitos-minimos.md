# Requisitos Mínimos
Son aquellas condiciones esenciales que deben cumplirse necesariamente para que un sistema operativo o un software pueda ser instalado. Sin la satisfacción de estos requisitos, la instalación es inviable o el funcionamiento del programa sería deficiente o imposible.
