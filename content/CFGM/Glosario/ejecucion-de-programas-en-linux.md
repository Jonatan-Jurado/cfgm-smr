# Ejecución de Programas en Linux
Proceso para iniciar y ejecutar archivos o programas en el sistema operativo Linux, el cual requiere los permisos necesarios por seguridad.

- _Permisos_: Linux bloquea la ejecución de programas y aplicaciones que no tienen los permisos necesarios.
- _Desde la terminal_: Se navega a la carpeta o directorio donde está el archivo a ejecutar.
- _Comando básico_: `/nombreArchivo` para ejecutarlo.
- _Como administrador (sudo)_: `sudo ./nombreArchivo` para instalar programas como administrador.
