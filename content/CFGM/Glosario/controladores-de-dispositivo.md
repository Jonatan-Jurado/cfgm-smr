# Controladores de Dispositivo
También conocidos como [[Drivers]], son programas específicos que permiten al [[Sistema Operativo]] interactuar correctamente con el [[Hardware]]. Tras instalar el Sistema Operativo, es prioritario instalar los [[Controladores]] de componentes como impresoras, tarjetas gráficas o adaptadores de red para asegurar su correcto funcionamiento.
