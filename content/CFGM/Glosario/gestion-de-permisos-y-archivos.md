# Gestión de Permisos y Archivos
Es la función del [[Sistema Operativo]] encargada de garantizar la seguridad y la integridad de la información. El sistema gestiona el acceso a los elementos del ordenador mediante [[Permisos]] de lectura, escritura y ejecución. Asimismo, organiza los ficheros dentro de un [[Sistema de Archivos]], controlando qué operaciones puede realizar cada usuario sobre ellos.
