# Conversión de binario a octal
Para realizar la conversión de binario a octal, se deben formar grupos de 3 dígitos binarios, teniendo como referencia la coma. Cada uno de estos grupos de dígitos binarios es un dígito en octal, por lo que se debe realizar la conversión correspondiente para cada grupo.
