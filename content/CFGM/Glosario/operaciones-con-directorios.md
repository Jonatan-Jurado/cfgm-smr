# Operaciones con directorios
Acciones más comunes que los usuarios realizan sobre los directorios en un sistema de archivos, generalmente a través de comandos.
- _Crear un directorio_: se utiliza el comando `mkdir`. Si el parámetro es solo un nombre, lo crea en el directorio actual. También es posible introducir una ruta como parámetro.
- _Cambiar de directorio_: se utiliza el comando `cd`, el cual tiene que ir acompañado de la ruta (relativa o absoluta) a la que se quiere ir.
- _Listar directorio_: se utiliza el comando `ls` para conocer el contenido de un directorio.
- _Copiar directorio_: se utiliza el comando `cp`.
- _Mover directorio_: se utiliza el comando `mv`. Este mueve un directorio junto con todos los archivos y directorios que contiene.
- _Eliminar directorio_: se utiliza el comando `rm`.
