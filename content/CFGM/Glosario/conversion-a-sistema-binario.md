# Conversión a Sistema Binario
Para convertir números desde base octal o hexadecimal a binario, se realiza el [[Proceso]] inverso a la agrupación. Cada dígito octal se transforma en tres dígitos binarios independientes, mientras que cada dígito hexadecimal se transforma en cuatro dígitos binarios, manteniendo siempre la posición respecto a la coma.
