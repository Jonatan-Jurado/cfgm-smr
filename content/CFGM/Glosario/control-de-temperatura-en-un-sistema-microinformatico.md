# Control de temperatura en un sistema microinformático
Proceso fundamental para mantener la temperatura de los ordenadores dentro de unos límites establecidos para que funcionen correctamente. Si la temperatura aumenta de forma considerable, puede producir un comportamiento anómalo del ordenador, llegando incluso a quemarse.
- _Generación de calor_: El procesador genera calor durante su funcionamiento, que se incrementa en función del tamaño del voltaje al que opere.
- _Método de refrigeración_: Se refrigera de forma constante mediante elementos de refrigeración por aire.
