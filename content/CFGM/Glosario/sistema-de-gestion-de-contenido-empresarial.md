# Sistema de gestión de contenido empresarial
Un sistema de gestión de contenido empresarial (ECM) permite a las empresas capturar, almacenar, gestionar y distribuir documentos y contenido de manera eficiente.
Algunos ejemplos incluyen:
- _SharePoint de Microsoft_
- _Alfresco_
- _OpenText_
