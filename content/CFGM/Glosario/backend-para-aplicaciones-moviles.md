# Backend para aplicaciones móviles
La parte de una aplicación móvil que se ejecuta en el servidor, encargada de gestionar servicios como la autenticación de usuarios, bases de datos en tiempo real y notificaciones push.
- _Ejemplo de servicio_: Firebase de Google.
