# Estructura de Directorios de Windows
Organización jerárquica de las carpetas fundamentales del [[Sistema Operativo]]:
* **\Boot**: Archivos críticos para el arranque del sistema.
* **\Archivos de programa**: Ubicación del [[Software]] instalado. Contiene "Common Files" para datos compartidos entre aplicaciones.
* **\ProgramData**: Carpeta (generalmente oculta) que almacena datos de configuración de aplicaciones compartidos por los usuarios, incluyendo el Menú Inicio y herramientas administrativas.
* **\PerfLogs**: Almacena registros de rendimiento y logs de aplicaciones.
* **\Usuarios**: Contiene los perfiles personales y datos de cada [[Usuario]] registrado en el sistema.
