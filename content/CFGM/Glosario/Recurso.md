# Recurso

Cualquier componente físico o lógico que [[El Sistema operativo]]|el Sistema operativo debe administrar y asignar para que los procesos puedan ejecutarse correctamente. Incluye elementos de [[Hardware]] (tiempo de [[CPU]], [[Memoria]] RAM|Memoria RAM]], espacio en disco, [[Periféricos]]) y elementos de [[Software]] (archivos, semáforos, sockets).
