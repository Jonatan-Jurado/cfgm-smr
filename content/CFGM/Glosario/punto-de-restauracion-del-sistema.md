# Punto de Restauración del Sistema
Es una herramienta de [[Windows]] que permite devolver el [[Sistema Operativo]] a un estado estable guardado con anterioridad. Esta funcionalidad crea copias de seguridad de la configuración del sistema y archivos críticos de forma automática o manual. Es una alternativa menos drástica que el formateo, permitiendo revertir cambios en el sistema si este se vuelve inestable tras una instalación o fallo de configuración, manteniendo la información del usuario.
