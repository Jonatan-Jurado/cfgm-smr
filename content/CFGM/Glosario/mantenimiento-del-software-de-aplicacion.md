# Mantenimiento del software de aplicación
Conjunto de tareas continuas que los sistemas operativos necesitan realizar para asegurar el correcto funcionamiento, corregir fallos y aumentar la fiabilidad del software instalado.
Tareas de mantenimiento comunes incluyen:
- _Paquetes de actualización_: comprobación y descarga de actualizaciones para el sistema operativo y las aplicaciones.
- _Copias de seguridad_: resguardar los archivos más importantes.
- _Archivos temporales_: borrado de archivos temporales.
- _Programas que no se utilizan_: desinstalación de software no utilizado.
- _Desfragmentación de discos_: gestión del sistema de archivos, aunque en Linux no es necesaria de la misma forma que en otros sistemas, sí existen herramientas de reparación.
