# Memoria SWAP

Mecanismo de [[Gestión de Memoria]]|gestión de Memoria que consiste en reservar un espacio en el [[Disco duro]] (normalmente una [[Partición]] dedicada) para actuar como una extensión virtual de [[La Memoria RAM|Memoria RAM]]|la Memoria RAM|Memoria RAM]]]]. Se utiliza para alojar datos que no caben en la RAM física, evitando el colapso del sistema por sobrecarga. También es fundamental para almacenar el estado del sistema durante la hibernación.
