# Windows (ordenadores personales)
Línea de productos creada por Microsoft para ordenadores personales, como parte de la estrategia de la compañía para dividir su oferta de productos. Windows 95 fue el primer sistema operativo de esta gama que incorporaba un entorno gráfico.
