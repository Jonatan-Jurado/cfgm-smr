# Velocidad de Transferencia en Unidades CD
La velocidad de referencia original (1x) para una [[Unidad de CD]] equivale a 150 KBps. Para determinar la velocidad real de transferencia de un dispositivo actual, se debe multiplicar su factor de velocidad (por ejemplo, 72x) por la tasa base de 150 KBps.
