# Árbol de directorios

Organización jerárquica y lógica de los datos en un [[Sistema de archivos]]. [[El Sistema operativo]]|El Sistema operativo [[Windows]] utiliza el [[Explorador de Archivos]] para representar gráficamente esta estructura, permitiendo la administración del equipo, la creación de elementos, la navegación y la ejecución de aplicaciones desde una [[Interfaz]] intuitiva.
