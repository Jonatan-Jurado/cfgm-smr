# Herramienta de montaje

Utensilios manuales utilizados por el técnico informático para el ensamblaje y reparación de equipos eléctricos. El uso de herramientas como alicates o destornilladores requiere medidas preventivas para evitar golpes, cortes o descargas eléctricas. Es obligatorio que cuenten con certificado de calidad, se utilicen exclusivamente para el fin que fueron diseñadas y se transporten de forma segura para evitar lesiones al operario.
