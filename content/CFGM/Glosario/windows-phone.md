# Windows Phone
Sistema operativo desarrollado por Microsoft para teléfonos inteligentes y otros dispositivos móviles, originalmente denominado Windows Mobile, que cambió a Windows Phone en 2014. No tuvo éxito en el mercado debido a la dominancia de Android y iOS. En 2015 se anunció su retirada, siendo sustituido por Windows 8, utilizado tanto en dispositivos de escritorio como móviles.
