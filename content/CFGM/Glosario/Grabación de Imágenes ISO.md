# Grabación de Imágenes ISO
[[Proceso]] mediante el cual se transfiere el contenido de un [[Archivo]] de imagen (ISO) a un soporte físico como un CD o [[DVD]], o se gestiona a través de [[Software]] especializado. En sistemas [[Windows]], se utilizan programas como Nero o Clone CD para seleccionar la grabadora y volcar la imagen. En entornos Linux (como Ubuntu), se emplean paquetes como ISO Master o Furius ISO Mount, que permiten no solo grabar, sino también crear, modificar, extraer archivos y restaurar dichas imágenes de forma estructurada.
