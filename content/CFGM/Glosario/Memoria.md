# Memoria

Componente o dispositivo físico utilizado para almacenar datos y programas de forma temporal o permanente. En el mantenimiento de sistemas, se clasifican según su volatilidad y función, siendo las principales [[La Memoria RAM]]|la Memoria RAM (almacenamiento volátil de acceso rápido para la ejecución de procesos) y las memorias de almacenamiento masivo.
