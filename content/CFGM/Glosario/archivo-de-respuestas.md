# Archivo de respuestas

Es un documento de configuración utilizado para automatizar la [[Instalación de un Sistema operativo]]|instalación de un Sistema operativo. Contiene todas las respuestas a las preguntas que el programa de instalación realizaría normalmente al [[Usuario]] (como la configuración regional, el nombre del equipo o la clave de producto), permitiendo que el [[Proceso]] se realice de forma desatendida y masiva.
