# Creación de máquinas virtuales
Proceso para establecer una nueva máquina virtual una vez instalado el software de virtualización. Se inicia seleccionando la opción "Create a new virtual machine".

Existen diferentes opciones:
-   Crear la máquina virtual sin instalar el sistema operativo de inmediato.
-   Indicar el sistema operativo que se utilizará durante la creación.
Aunque se posponga la instalación, es necesario indicar el tipo de sistema operativo. Finalmente, se configuran las características de la máquina virtual, como la cantidad de RAM dedicada o el espacio de almacenamiento del disco duro.
