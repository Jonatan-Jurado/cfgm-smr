# Diagnósticos de Red de Windows
Es una herramienta integrada en el [[Sistema Operativo]] diseñada para identificar y resolver problemas de conectividad de forma automatizada. El asistente realiza un chequeo del sistema y de los adaptadores de red, ofreciendo soluciones guiadas para restablecer el acceso a la red o a [[Internet]].
