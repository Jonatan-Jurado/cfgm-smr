# Medición de tensión
Técnica utilizada para comprobar si llega suficiente corriente a los dispositivos para su correcto funcionamiento. Se realiza utilizando un polímetro para medir la tensión que entra al dispositivo.

De esta manera, se puede localizar si la avería es del propio dispositivo o del elemento que le proporciona la electricidad.
