# Actualización del sistema operativo
Proceso de instalar mejoras, parches de seguridad o nuevos controladores en el sistema operativo para mantenerlo al día. En Windows, estas actualizaciones se publican en la plataforma Windows Update.

Dependiendo de su función, las actualizaciones de cualquier sistema operativo Windows se dividen en tres tipos:
- _Actualizaciones críticas_: Son necesarias puesto que mejoran la seguridad del sistema.
- _Service Packs_: Son conjuntos de programas que contienen actualizaciones para mejorar el sistema operativo, suelen ser de gran peso.
- _Controladores de dispositivos o drivers_: Son los controladores que se deben instalar para poder dar soporte a los nuevos dispositivos.

La opción recomendada es permitir la instalación de actualizaciones automáticas, aunque esto puede ralentizar el sistema operativo.
