# Sistemas de Refrigeración
Elementos encargados de mantener la temperatura del [[Microprocesador]] dentro de límites seguros para evitar fallos o daños físicos. Se compone habitualmente de:
* **[[Disipador]] (Heatsink):** Pieza metálica (aluminio o cobre) que absorbe el calor del procesador y lo transfiere al aire.
* **[[Ventilador]] (Fan):** Elemento activo que genera un flujo de aire constante para enfriar el disipador.
