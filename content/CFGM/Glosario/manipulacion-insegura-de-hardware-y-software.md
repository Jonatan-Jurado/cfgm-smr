# Manipulación Insegura de Hardware y Software
Es una norma fundamental no manipular ningún elemento hardware ni configuración software sin estar previamente seguro de lo que se hace. En caso de duda, se debe consultar fuentes fiables como internet (páginas oficiales) o el manual de usuario del elemento en cuestión.
