# Cloud Computing
Se ha convertido en una herramienta imprescindible para las organizaciones debido a la gran variedad de servicios que ofrece: almacenamiento de datos, acceso a bases de datos, aplicaciones, programas informáticos y software de todo tipo, streaming de vídeo y redes sociales.

Su protocolo de funcionamiento básico es el siguiente:
- _El usuario utiliza un dispositivo_: para conectarse a internet, ya sea a través de una red fija o inalámbrica.
- _El proveedor de internet se encarga de llevar los datos_: desde el dispositivo del usuario hasta el servidor de destino, utilizando una dirección IP o una dirección web.
- _El servidor procesa los datos_: opera con la información solicitada y devuelve una respuesta al usuario.
