# Elementos requeridos para un incendio
Para que un incendio sea posible y se mantenga, se requieren cuatro elementos principales que forman el denominado "tetraedro del fuego":

_Elementos_:
- _Comburente_: Generalmente el oxígeno del aire.
- _Combustible_: El material que arde.
- _Calor_: La energía necesaria para iniciar y mantener la combustión.
- _Reacción en cadena_: La progresión de la combustión que se autoalimenta.
