# Creación de Imágenes ISO
Proceso para generar un archivo de imagen ISO, que es una copia comprimida de un CD o DVD, con el propósito de grabarla posteriormente en un soporte físico.
- _Procedimiento general_: Descargar la imagen y luego grabarla en un soporte físico para su uso en un DVD de forma más rápida.
- _En Windows_:
    - _1_: Se inserta el CD en la grabadora.
    - _2_: Hacer doble clic en la imagen ISO para abrir el programa a utilizar (ej. Nero, Clone CD).
    - _3_: Elegir la grabadora y seleccionar la opción de Grabar.
- _En Ubuntu Linux_: Utiliza paquetes como ISO Master o Furius ISO Mount.
    - _1_: Archivo → Nuevo.
    - _2_: Seleccionar los archivos y carpetas que formarán parte del proceso.
    - _3_: Agregar.
    - _4_: En caso de error, Eliminar.
    - _5_: Crear un Nuevo directorio.
    - _6_: Guardar los archivos mediante Archivo → Guardar como.
    - _7_: Para ver el contenido de la imagen, hacer doble clic sobre ella.
    - _8_: Para extraer los archivos, clic en Extraer.
