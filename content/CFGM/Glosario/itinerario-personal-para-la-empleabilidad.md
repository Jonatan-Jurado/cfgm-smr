# Itinerario personal para la empleabilidad
Un proceso fundamental para asegurar una buena preparación profesional, que implica comparar el perfil disponible de una persona con el perfil exigible de un título o puesto. Este proceso tiene como fin identificar las habilidades y conocimientos necesarios a desarrollar para alcanzar las metas profesionales. Actúa como un mapa para el viaje profesional, ayudando a determinar la posición actual, el destino deseado y las acciones necesarias para llegar allí.
