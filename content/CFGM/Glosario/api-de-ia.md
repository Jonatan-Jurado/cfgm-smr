# API de IA
Interfaces de programación de aplicaciones que permiten implementar soluciones de inteligencia artificial como reconocimiento de voz, procesamiento de lenguaje natural o visión por computadora.
- _Ejemplos de proveedores_: Google Cloud, IBM Watson, Azure Cognitive Services.
