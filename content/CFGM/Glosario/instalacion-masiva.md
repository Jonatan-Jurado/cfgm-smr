# Instalación masiva
Método que permite realizar instalaciones de forma rápida y cómoda en múltiples equipos. Consiste en crear una imagen de un disco duro y luego restaurar esta imagen a través de la red en diferentes equipos simultáneamente.
Pasos para realizar una instalación masiva:
- _Generar un archivo de respuestas_: para que la instalación se realice de forma desatendida.
- _Crear la imagen_: del sistema operativo configurado.
- _Almacenar la imagen y el archivo de respuestas_: en un recurso compartido para que puedan ser accesibles desde cualquier equipo.
Un ejemplo de software para instalación masiva es Symantec Ghost Corporate Edition (Norton Ghost).
