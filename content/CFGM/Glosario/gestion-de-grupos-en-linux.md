# Gestión de Grupos en Linux
Administración de agrupaciones de usuarios para facilitar la asignación de [[Permisos]]. Se gestiona mediante los comandos `groupadd` (creación), `groupmod` (modificación del GID o nombre) y `groupdel` (eliminación). Para asociar un usuario a un grupo existente, se utiliza habitualmente el comando `adduser`.
