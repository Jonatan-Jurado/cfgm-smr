# UEFIBIOS
Es un tipo de BIOS modernizada que ha añadido una interfaz gráfica, permitiendo utilizar tanto el teclado como el ratón, lo que aumenta su usabilidad.

- _Diferencias frente a las BIOS tradicionales_:
    - _Independencia del sistema operativo_: es independiente del sistema operativo. Las BIOS tradicionales pueden tener características asociadas a la ejecución del sistema operativo.
    - _Soporte de sistemas operativos_: soporta sistemas operativos de 32 y 64 bits. Las BIOS tradicionales solo soportan los de 16 bits.
    - _Funcionalidades añadidas_: permite configurar el Secure Boot y agiliza el arranque del sistema operativo.
