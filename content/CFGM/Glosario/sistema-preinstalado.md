# Sistema preinstalado

Modelo de distribución de [[Software]] donde [[El Sistema operativo]]|el Sistema operativo y los [[Controladores]] necesarios ya vienen configurados de fábrica por el fabricante. Este método busca agilizar el despliegue de equipos nuevos y evitar la distribución de copias no autorizadas, facilitando al [[Usuario]] final un entorno listo para usar desde el primer encendido.
