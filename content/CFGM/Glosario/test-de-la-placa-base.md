# Test de la Placa Base
Proceso de verificación recomendado después de conectar la fuente de energía a la placa base, con el fin de comprobar si los pasos realizados durante el montaje son correctos y si todos los elementos funcionan adecuadamente.

El testeo consiste en:
- _Conectar la fuente de alimentación_: a la placa base.
- _Conectar el monitor_: al equipo.
- _Enchufar el ordenador_: para iniciar el sistema y verificar su funcionamiento.
