# Fases de Instalación de un Sistema Operativo
[[Proceso]] estructurado para implementar un [[Sistema Operativo]] en un equipo:
1. **Planificación:** Análisis previo para decidir entre actualizar o formatear (instalación desde cero), previendo posibles errores y verificando requisitos.
2. **Preparación:** Configuración del [[Hardware]] a través de la [[BIOS]] para establecer el [[Orden de Arranque]] (boot priority) desde el dispositivo que contiene el instalador.
3. **Instalación y Configuración:** Ejecución del asistente para definir particiones, usuarios y parámetros básicos del sistema.
