# Conversión de binario a hexadecimal
Para realizar la conversión de binario a hexadecimal, se deben formar grupos de 4 dígitos binarios, teniendo como referencia la coma. Cada uno de estos grupos de dígitos binarios es un dígito en hexadecimal, por lo que se debe realizar la conversión correspondiente para cada grupo.
