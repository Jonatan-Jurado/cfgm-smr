# Requisito recomendado

Especificaciones técnicas que, si bien no son estrictamente necesarias para que el sistema funcione, son aconsejables para garantizar una experiencia de [[Usuario]] fluida, un rendimiento estable y el aprovechamiento óptimo de todas las funcionalidades del [[Software]] o [[Sistema operativo]] instalado.
