# Comando dpkg
El comando `Dpkg` es la herramienta base para la gestión de paquetes en distribuciones Linux basadas en Debian. El parámetro específico `Dpkg -l` permite al Administrador del Sistema obtener un listado detallado y completo de todo el Software instalado. Esta función es esencial para el Mantenimiento del Inventario de Software, la comprobación del correcto funcionamiento del sistema y el seguimiento de los cambios realizados en el equipo.
