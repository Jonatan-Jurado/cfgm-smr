# Shortest Job Next

Es un algoritmo de planificación que selecciona para su ejecución aquel trabajo que requiere el menor tiempo de [[Servicio]] de entre todos los que se encuentran en espera. Este método busca minimizar el [[Tiempo de espera]] medio, aunque requiere que el sistema o el [[Usuario]] estimen previamente la duración del [[Proceso]].
