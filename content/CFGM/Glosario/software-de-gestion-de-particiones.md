# Software de Gestión de Particiones
Herramientas o programas informáticos diseñados para realizar diversas operaciones con particiones en un sistema.
- _Disponibilidad_: Algunos ya forman parte de determinados sistemas operativos, mientras que otros pueden instalarse aparte.
- _Características_: Suelen ser cómodos e intuitivos para facilitar su gestión por cualquier usuario.
