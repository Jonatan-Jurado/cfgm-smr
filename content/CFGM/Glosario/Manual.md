# Manual (Documentación Informática)
Un manual, en el contexto de la documentación informática, detalla las características de las diferentes funciones de un dispositivo o aplicación. Es una herramienta fundamental para aprender a manejar una nueva aplicación, ejecutarla, configurarla y realizar sus actividades básicas.

Se recomienda que tenga una estructura sencilla que incluya:
-   _Una página para la portada_: con el título de la guía y otros aspectos importantes.
-   _Una segunda página_: con las referencias para los derechos de autor.
-   _Introducción_: explicando el uso que se le va a dar a la guía.
-   _Una página para el índice_: referenciando todas las páginas.
-   _Varias páginas finales_: mostrando la utilización y las novedades respecto al producto anterior.

La elaboración de un manual suele realizarse en programas especializados como PDF Creator o Adobe Acrobat Professional, siguiendo normas básicas como:
-   _Portada_
-   _Encabezado y pie de página_
-   _Redacción del contenido_
-   _Página final_
-   _Índice_
-   _Cierre del documento_
