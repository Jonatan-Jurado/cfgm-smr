# Comando de directorio

Conjunto de instrucciones de la [[Interfaz]] de línea de comandos|Interfaz de línea de comandos]] destinadas a la gestión de carpetas. Entre las funciones principales se encuentran:
- **mkdir**: Creación de carpetas mediante rutas relativas o absolutas.
- **cd**: Navegación por la estructura del [[Sistema de archivos]].
- **dir / tree**: Visualización del contenido de forma textual o gráfica (árbol).
- **xcopy**: Copia de [[Directorios]]; requiere el modificador `/e` para incluir subdirectorios vacíos o con contenido.
- **move**: Traslado de Directorios y su contenido completo.
- **rd**: Eliminación de carpetas; se utiliza con el modificador `/s` para borrar estructuras de forma recurrente.
