# Fichero especial

Son archivos específicos utilizados en sistemas Linux para establecer la comunicación entre [[El Sistema operativo]]|el Sistema operativo y los diferentes [[Periféricos]] o dispositivos de [[Hardware]]. A través de ellos, el sistema puede leer o escribir datos en el Hardware como si se tratara de un [[Archivo]] común.
