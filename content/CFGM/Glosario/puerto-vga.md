# Puerto VGA
El conector Video Graphics Array ([[VGA]]) es una interfaz estándar de salida de vídeo que se utiliza para conectar la [[Tarjeta Gráfica]] con dispositivos de visualización analógicos, como monitores antiguos o proyectores. Aunque es una tecnología analógica, sigue siendo un punto de referencia en la conectividad básica de sistemas microinformáticos.
