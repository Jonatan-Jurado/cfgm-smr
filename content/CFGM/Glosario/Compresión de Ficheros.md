# Compresión de Ficheros
Proceso técnico que consiste en reducir el peso o tamaño de un archivo o directorio para que ocupe menos espacio de almacenamiento, sin que ello suponga una pérdida de información. Para realizar esta tarea mediante interfaz gráfica en Windows, se suelen emplear herramientas de terceros como WinRAR o 7zip.
