# Tecnología de Virtualización
Es una característica integrada en los procesadores que permite ejecutar múltiples sistemas operativos invitados de forma aislada sobre un sistema operativo anfitrión o directamente sobre el hardware (hipervisor).

- _Requisitos para Intel_: Procesador Intel Core i5 o superior.
- _Requisitos para AMD_: Procesadores con Socket AM3, Socket AM2, Socket S1 o Socket F.
- _Rendimiento_: Si no se cumplen los requisitos, la virtualización puede ralentizar el rendimiento del equipo.
