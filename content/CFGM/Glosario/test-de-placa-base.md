# Test de Placa Base
Prueba diagnóstica preventiva que se realiza durante el [[Proceso]] de montaje para verificar el correcto funcionamiento de los componentes críticos. Consiste en conectar la [[Fuente de Alimentación]] a la [[Placa Base]], el monitor y [[Periféricos]] básicos para comprobar si el sistema arranca y los elementos instalados hasta el momento responden adecuadamente antes de finalizar el ensamblaje.
