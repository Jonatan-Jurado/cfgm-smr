# Hyper-V
Software de virtualización de Microsoft diseñado para procesadores de 64 bits. Se utiliza en sistemas operativos de servidores como Windows Server 2008, permitiendo virtualizar hasta tres máquinas anidadas (una dentro de otra).

Actualmente, también está disponible en sistemas operativos cliente (como Windows 8, 8.1 y 10). Es gratuito porque está incluido dentro del sistema operativo de Microsoft.
