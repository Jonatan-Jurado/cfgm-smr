# Script administrativo

[[Archivo]] de texto que contiene una serie de comandos u órdenes que se ejecutan de forma secuencial por un [[Intérprete de comandos]]. Su propósito fundamental es la [[Automatización de Tareas]] repetitivas de gestión, como la creación masiva de usuarios, la realización de copias de seguridad, el [[Inventario de Software]]|inventario de Software o la configuración masiva de parámetros de red, aumentando la eficiencia y reduciendo errores humanos.
