# Fabricación Aditiva
Proceso de fabricación que construye objetos tridimensionales capa por capa a partir de datos digitales.
El proceso sigue estos pasos:
- _Creación de un modelo digital tridimensional_: mediante un software de diseño asistido por ordenador (CAD).
- _División del modelo_: en capas horizontales muy delgadas.
- _Construcción del objeto_: por una máquina de fabricación aditiva (una impresora 3D), depositando material (como plástico, metal, cerámica o incluso material biológico) de acuerdo con las especificaciones de cada capa, fusionándolo, solidificándolo o uniendo los materiales según el método específico de la impresora.
Características:
- _Agrega material_: de manera incremental para crear el objeto deseado.
Ventajas:
- _Capacidad de crear geometrías complejas_
- _Personalización rápida y económica_
- _Reducción de desperdicios de material_
- _Capacidad de producir componentes con propiedades específicas y optimizadas_
Usos:
- _Fabricación de prototipos_
- _Piezas personalizadas_
- _Producción_
