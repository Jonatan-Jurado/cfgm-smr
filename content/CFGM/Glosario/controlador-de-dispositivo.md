# Controlador de dispositivo
Soporte de software que el fabricante debe suministrar junto con un dispositivo hardware para que el sistema operativo sea capaz de reconocerlo y, consecuentemente, permitir su uso. Es necesario suministrar los controladores de los dispositivos instalados al formatear un equipo. Aunque los sistemas operativos vienen con algunos controladores preinstalados, para modelos nuevos es frecuente que deban instalarse de nuevo.
