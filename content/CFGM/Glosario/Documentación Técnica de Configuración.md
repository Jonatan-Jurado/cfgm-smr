# Documentación Técnica de Configuración
Guía proporcionada por el fabricante que establece los requisitos mínimos, parámetros recomendados y pasos a seguir para la instalación de [[Software]] o sistemas operativos. Permite distinguir entre una instalación recomendada (automática) y una personalizada (donde el usuario selecciona componentes específicos).
