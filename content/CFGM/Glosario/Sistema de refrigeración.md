# Sistema de refrigeración

Conjunto de elementos diseñados para evacuar el calor generado por los componentes electrónicos, especialmente el [[Microprocesador]]. Puede ser de tipo activo (ventiladores), pasivo (disipadores de calor) o líquida, garantizando que el [[Hardware]] funcione dentro de rangos de temperatura seguros.
