# Instalación del Sistema de

refrigeración del procesador El [[ventilador]] y el disipador propio del [[microprocesador]] completa el sistema de refrigeración específico del elemento más importante de la [[placa base]]: el microprocesador. Los sistemas de refrigeración incluyen diversos tipos de anclajes para fijarlos a la placa. Antes de empezar, debemos leer en el manual la forma de realizar dichos anclajes. Como ya hemos visto, la función que tienen estos elementos es evacuar el sobrecalentamiento del micro- procesador, por lo que es imprescindible que este lo más próximo posible a este. Una vez probados los anclajes del disipador, procedemos a quitar el envoltorio y nos fijaremos en si trae almohadilla térmica, ya que, de no tener dicha almohadilla, debemos añadir en este momento la pasta térmica. ¡RECUERDA! Para facilitar aún más este tránsito de calor, se reco- mienda untar entre el pro- cesador y el disipador una pasta térmica conductora, o bien disponer una almoha- dilla termoconductora. Montaje y mantenimiento de equipos 59 Una vez untada la pasta, fijaremos los anclajes consultando el manual. Normalmente se atornillan a la placa, pero, al existir tantos modelos, el manual nos sacará de dudas. Seguidamente podemos fijar el ventilador una vez fijado el disipador, y así completaremos el sistema de refrigeración. El caso más común es incluir palanca de anclaje, como ya vimos con el procesador. Por tanto, se procede igual, con la palanca abierta se ajusta el ventilador y para bloquear y asegurar el ventilador se cierra la palanca. Para terminar el proceso, quedaría conectarlo a la placa base mediante el conector CPU_FAN, y a la fuente de alimentación eléctrica. 7.4. Fijación de módulos de me- moria RAM El siguiente componente para instalar sería [[la memoria RAM]], una memoria volátil que almacena los datos para llevarlos al procesador. Para ello, lo primero sería localizar las ranuras específicas para los módulos de memoria RAM. A continuación, debemos comprobar si la placa base y los módulos de la memoria son compatibles. Una vez asegu- rada su compatibilidad, procedemos a quitar el embalaje para iniciar la instalación insertando el módulo de RAM en su ranura correspondiente. Cada ranura presenta unas pestañas laterales para asegurar la instalación de los módulos. Para poder instalar los módulos, las pestañas deben estar abiertas. Después, cogeremos la memoria sosteniéndola solamente por los bordes para introducirla en la ranura. Una vez realizado este paso, las pestañas se deberían cerrar sin ninguna presión, fijando los módulos a la placa base. Instalación de la fuente de alimentación Normalmente, la fuente de alimentación viene ya montada de fábrica en [[la caja]], pero, por si acaso o por si hubiera que reemplazarla, veamos su proceso de instalación. Primero debemos buscar el hueco habilitado para dicho dispositivo (suele estar en la parte trasera de la caja). Segui- damente, veremos las características técnicas de la fuente de alimentación para ver si es compatible con la placa base donde se va a conectar. Una vez realizadas las comprobaciones, debemos deslizar la fuente por el hueco habilitado hasta llegar al tope y proceder a fijar con los tornillos para su seguridad. Una vez colocada, podemos conectar la fuente de energía a la placa base mediante el conector apropiado. Llegado este punto, es recomendable comprobar el proceso, para lo que realizamos un test de la placa base. Con ello comprobaremos si los pasos realizados hasta ahora son los correctos. El testeo consiste en conectar la fuente de alimentación a la placa base, conectar el monitor y enchufar el ordenador para comprobar si todos los elementos funcionan.
