# Comando gzip

Herramienta de consola utilizada para comprimir y descomprimir archivos en formato `.gz`. A diferencia de otras herramientas, `gzip` solo comprime archivos individuales y no [[Directorios]] completos de forma nativa. Su uso típico incluye la opción `-9` para obtener el máximo factor de compresión y la opción `-d` para realizar la descompresión (equivalente al comando `gunzip`).
