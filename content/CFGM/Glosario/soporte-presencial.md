# Soporte Presencial
También conocido como soporte *in situ*, es la vía de resolución que se utiliza cuando la avería no puede ser solventada de forma telefónica ni remota. Requiere que el técnico se desplace físicamente a la ubicación del equipo para realizar intervenciones sobre el [[Hardware]] o configuraciones críticas de red local.
