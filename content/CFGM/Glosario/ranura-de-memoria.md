# Ranura de memoria

Es un conector eléctrico situado en la [[Placa base]] diseñado para albergar módulos de [[Memoria]] RAM|Memoria RAM]]. Estas ranuras cuentan con pestañas laterales de seguridad que deben abrirse previamente a la instalación y que se cierran automáticamente (o mediante presión manual) para fijar el módulo, asegurando el contacto correcto entre los pines y el [[Bus]] de datos|Bus de datos]].
