# Logística
El conjunto de medios y métodos necesarios para llevar a cabo la organización de una empresa, especialmente en lo referente a la distribución. La digitalización implica el uso de plataformas para la gestión de envíos y entregas para pedidos en línea.
- _Ejemplo de herramienta_: ShipStation
