# Parallels
Software de virtualización para el sistema operativo Mac OS con procesadores Intel, propiedad de Parallels. Permite utilizar las aplicaciones de Windows en Mac OS sin necesidad de BootCamp, virtualizando Windows dentro del Mac y reutilizando la configuración de una partición existente.

Además, permite virtualizar otros sistemas operativos como Mac OS, Windows (en sus versiones 7, 8.1 y 10) y Linux, entre otros. Es un software de pago, pero se puede realizar una prueba de forma gratuita.
