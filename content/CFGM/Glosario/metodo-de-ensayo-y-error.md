# Método de ensayo y error

Técnica de diagnóstico utilizada para identificar componentes defectuosos. Consiste en arrancar la máquina con la configuración mínima de elementos indispensables para su funcionamiento e ir conectando el resto de los componentes uno a uno. De este modo, se observa la respuesta de la [[Placa base]] ante cada nueva conexión hasta localizar el dispositivo que provoca el fallo.
