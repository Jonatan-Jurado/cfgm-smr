# Signo y Magnitud
Es un método para representar números enteros en binario donde el [[Bit]] situado más a la izquierda (Bit más significativo) se reserva para el signo. Si este Bit es 0, el número es positivo; si es 1, el número es negativo. El resto de los bits representan el valor absoluto o módulo del número. Su principal desventaja técnica es la existencia de una doble representación para el número cero (cero positivo y cero negativo), lo que complica la implementación de circuitos aritméticos.
