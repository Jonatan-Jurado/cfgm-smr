# Extensible Firmware Interface
Estándar moderno que utiliza tablas de particiones de tipo GPT (GUID Partition Table). A diferencia del sistema MBR, permite la creación de hasta 128 particiones por disco y ofrece interfaces gráficas con capacidades de acceso remoto para facilitar la resolución de problemas en el sistema.
