# Permisos de Archivo
Son reglas de acceso que regulan las operaciones básicas de lectura, escritura y ejecución para garantizar la seguridad del [[Sistema de Archivos]]. A diferencia de los atributos, los [[Permisos]] se establecen de forma específica para cada usuario o grupo, permitiendo restringir quién puede interactuar con cada recurso.
