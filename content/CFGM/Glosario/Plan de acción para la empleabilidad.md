# Plan de acción para la empleabilidad
Un conjunto de estrategias y pasos diseñados para cerrar las brechas identificadas entre el perfil disponible y el perfil exigible, con el objetivo de mejorar la empleabilidad de una persona. Este plan puede incluir:
- _Formación adicional_: Tomar cursos, talleres o certificaciones.
- _Ganar experiencia_: Realizar prácticas o trabajar en proyectos que proporcionen la experiencia necesaria.
- _Desarrollar habilidades_: Participar en programas o actividades que ayuden a mejorar las habilidades generales.
- _Buscar mentores_: Obtener consejos y orientación de profesionales experimentados en el campo.
