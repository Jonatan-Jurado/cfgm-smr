# Instalación de sistema operativo

Es el [[Proceso]] técnico de cargar el [[Software]] base en un equipo informático. Este Proceso incluye la selección del tipo de instalación, la preparación de las [[Particiones de Disco]] necesarias y la definición de parámetros iniciales críticos. Es fundamental asegurar la disponibilidad de los medios físicos de instalación, como memorias USB con imágenes ISO o [[Dispositivos de Almacenamiento]] externo, para evitar fallos de [[Hardware]] durante el procedimiento.
