# Clasificación de Computadoras
Según su capacidad, tamaño y propósito, las computadoras se pueden categorizar en:
* **Supercomputadoras:** Diseñadas para cálculos complejos y masivos.
* **Macrocomputadoras (Mainframes):** Sistemas potentes para procesar grandes volúmenes de datos.
* **[[Estaciones de Trabajo]] (Workstations):** Equipos de altas prestaciones para tareas profesionales.
* **Minicomputadoras:** Sistemas de rango medio.
* **[[Terminales ligeros]] (Thin Clients):** Equipos dependientes de un servidor central para procesar la información.
