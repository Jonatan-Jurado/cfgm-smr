# Partición de disco

División lógica de una unidad de almacenamiento física que permite organizar los datos de forma independiente. Cada [[Partición]] puede actuar como una unidad propia y es el paso previo necesario para poder aplicar un formato o [[Sistema de archivos]] a un [[Disco duro]].
