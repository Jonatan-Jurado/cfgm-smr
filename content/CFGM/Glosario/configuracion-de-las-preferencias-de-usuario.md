# Configuración de las preferencias de usuario
Opciones que permiten al usuario de un sistema operativo, como Windows 10, personalizar la interfaz gráfica de usuario (GUI) según sus gustos y necesidades.

Elementos configurables incluyen:
- _Barra de tareas_: ubicada en la parte inferior de la pantalla, contiene aplicaciones y accesos directos. El usuario puede elegir qué elementos se muestran, ocultarla y organizar su contenido.
- _Ventanas_: cada aplicación se abre en la interfaz gráfica en forma de ventana, que típicamente incluye tres botones en su parte superior para controlar su estado (minimizar, maximizar/restaurar, cerrar).

Un ejemplo de preferencia personalizable es el _tema_, que en Windows 10 es un conjunto de sonidos, iconos y estilos de puntero del ratón que personaliza el entorno de trabajo.
