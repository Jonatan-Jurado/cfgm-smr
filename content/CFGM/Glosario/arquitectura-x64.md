# Arquitectura x64

Arquitectura de procesador de 64 bits que ofrece una mayor capacidad de procesamiento de datos. Una de sus principales ventajas es la retrocompatibilidad, ya que permite la instalación y ejecución de programas diseñados tanto para arquitecturas de 64 bits como de 32 bits (x86).
