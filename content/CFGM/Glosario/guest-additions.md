# Guest Additions
Un componente necesario en VirtualBox para implementar la configuración que permite utilizar cualquier recurso compartido de forma automática.

Sus ventajas principales son:
- _Transferencia de archivos_: permite arrastrar archivos entre el sistema operativo anfitrión y el invitado para transferirlos.
- _Acceso a recursos_: facilita enormemente el acceso a recursos del sistema anfitrión.
- _Interfaz para periféricos_: provee una interfaz que facilita la compartición de periféricos (como memorias USB, ratón, teclado, CD, DVD, etc.).
