# Base de datos NoSQL
Las bases de datos NoSQL (Not Only SQL) ofrecen nuevas formas de almacenar y procesar grandes volúmenes de datos no estructurados o semiestructurados. Son especialmente útiles para entornos en los que la estructura de los datos es compleja, la escala es masiva y se requiere un procesamiento rápido en tiempo real. Son altamente escalables y flexibles.
- _Casos de uso_: aplicaciones web, IoT, análisis de big data
- _Ejemplos_: MongoDB, Cassandra, Redis, Couchbase
