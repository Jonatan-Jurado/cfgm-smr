# Recogida selectiva

Procedimiento técnico estipulado para clasificar y tratar de manera diferenciada los distintos materiales y componentes informáticos desechados. Es la medida principal para asegurar que los residuos peligrosos o contaminantes reciban el tratamiento adecuado, permitiendo el reciclaje de piezas y la eliminación segura de sustancias nocivas para el ecosistema.
