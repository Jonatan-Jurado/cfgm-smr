# Jerarquía de directorios de Linux

Estructura organizada de carpetas que componen el sistema operativo. Los directorios principales incluyen:
- **/bin y /sbin:** Comandos básicos y de administración del sistema.
- **/boot:** Archivos necesarios para el arranque del equipo.
- **/dev:** Archivos que representan los dispositivos de hardware.
- **/etc:** Ficheros de configuración del sistema y servicios.
- **/home:** Carpetas personales de los usuarios.
- **/root:** Directorio personal del administrador del sistema.
- **/lib:** Librerías esenciales para el funcionamiento de los binarios.
- **/mnt:** Punto de montaje para sistemas de archivos temporales o dispositivos externos.
- **/proc:** Sistema de archivos virtual con información del kernel y procesos.
- **/var:** Archivos de contenido variable como logs o bases de datos.
- **/usr:** Aplicaciones y archivos de lectura para los usuarios.
- **/tmp:** Archivos temporales del sistema.
