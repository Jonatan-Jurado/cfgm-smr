# Apache Cassandra
Es una base de datos NoSQL distribuida diseñada para manejar grandes volúmenes de datos en un entorno distribuido y escalable horizontalmente.
- _Uso_: en aplicaciones que requieren alta disponibilidad y rendimiento.
- _Ejemplos de aplicaciones_: redes sociales, análisis de registros y aplicaciones de IoT.
