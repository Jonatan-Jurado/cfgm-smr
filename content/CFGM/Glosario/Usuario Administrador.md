# Usuario Administrador
Es el usuario con control total sobre el equipo.
_Uso recomendado_: Solo debe usarse cuando es necesario, como para instalar y desinstalar software.
_Requisito_: Es obligatorio que exista, al menos, una cuenta de este tipo.
