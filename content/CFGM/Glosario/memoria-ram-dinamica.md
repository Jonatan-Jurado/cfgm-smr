# Memoria RAM Dinámica
Denominada técnicamente como DRAM (Dynamic RAM), es un tipo de memoria que requiere un [[Proceso]] de refresco constante de los datos almacenados para evitar que se pierdan. Es el tipo de memoria más común para la RAM principal debido a que es más económica de fabricar, aunque es más lenta en comparación con la memoria estática.
