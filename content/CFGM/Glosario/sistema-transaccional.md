# Sistema Transaccional
Un sistema transaccional es un tipo de sistema de información cuya función es recolectar, almacenar, modificar y recuperar la información generada por las transacciones de una organización.

Sus funciones son:
- _Mantener la seguridad y la consistencia de los datos_.
- _Deshacer operaciones para evitar errores_.
- _Controlar y administrar múltiples transacciones en un mismo momento_.

Para que un sistema se considere transaccional, debe pasar el Test ACID. Estos sistemas son implementados en softwares o páginas web que se encargan de la administración de entradas para eventos, viajes y ventas, entre otros.
