# Cara de disco

Cada una de las dos superficies útiles de un plato o disco que integra un [[Disco duro]] magnético|Disco duro magnético]]. Debido a que los platos tienen dos caras, el sistema puede escribir y leer datos en ambas superficies mediante el uso de cabezales independientes para cada una.
