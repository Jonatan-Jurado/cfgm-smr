# Manual de usuario
Documentos que sirven de guía para el proceso de montaje de un equipo informático. Están diseñados por el fabricante del componente y, por tanto, detallan las especificaciones técnicas del producto, así como el procedimiento a seguir para su correcta instalación y funcionamiento.

- _Importancia_: Son guías esenciales para el proceso de montaje, proporcionando información detallada del fabricante.
- _Ejemplo destacado_: El manual de la placa base es uno de los más importantes.
