# Preinstalación
Proceso que permite realizar instalaciones personalizadas del sistema operativo utilizando herramientas específicas.
Las herramientas de preinstalación suelen ofrecer las siguientes características:
- _Personalizar la interfaz del sistema_: como el fondo, tema, gadgets u opciones de escritorio.
- _Añadir nuevos ajustes_.
- _Deshabilitar servicios_.
- _Eliminar elementos no necesarios_.
- _Colocar actualizaciones, drivers o aplicaciones al instalar_.
Un ejemplo de herramienta es RT7 Lite, que ofrece la posibilidad de crear imágenes de diferentes sistemas a partir de una ISO estándar de instalación.
