# Unidad de Medida de Almacenamiento
Las unidades de medida de almacenamiento son las formas estandarizadas de cuantificar la capacidad de un dispositivo para guardar información digital. Dependiendo del dispositivo, las unidades más utilizadas pueden ser megabytes o gigabytes. El tipo de información a almacenar también influye en la unidad utilizada.

- _Byte (B)_: Equivale a 2^0 = 1.
- _Kilobyte (Kb)_: Equivale a 2^10 = 1024. Se utiliza, por ejemplo, para medir el tamaño de un fichero de texto.
- _Megabyte (Mb)_: Equivale a 2^20 = 1048576. Se utiliza, por ejemplo, para medir el tamaño de una canción en formato MP3.
- _Gigabyte (Gb)_: Equivale a 2^30 = 1073741824.
- _Terabyte (Tb)_: Equivale a 2^40 = 1099511627776.
- _Petabyte (Pb)_: Equivale a 2^50 = 1125899906842624.
- _Exabyte (Eb)_: Equivale a 2^60 = 1152921504606846976.
- _Zettabyte (Zb)_: Equivale a 2^70 = 1180591620717411303424.
- _Yottabyte (Yb)_: Equivale a 2^80 = 1208925819614629174706176.
