# Fichero de dispositivo

Son archivos especiales ubicados en la [[Ruta]] `/dev` en sistemas Linux que actúan como puentes de comunicación entre [[El Sistema operativo]]|el Sistema operativo y el [[Hardware]]. Estos ficheros permiten interactuar con el [[Controlador]] (driver) correspondiente a cada [[Periférico]] para establecer su configuración y funcionamiento correcto.
