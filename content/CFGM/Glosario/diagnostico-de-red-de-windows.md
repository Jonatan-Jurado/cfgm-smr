# Diagnóstico de red de Windows

Es una herramienta integrada en [[El Sistema operativo]]|el Sistema operativo [[Windows]] diseñada para identificar y resolver de forma automatizada problemas de conectividad. El asistente realiza un chequeo del sistema y de los parámetros de red, actuando como una guía para que el [[Usuario]] pueda restablecer el acceso a [[Internet]] o a los recursos locales.
