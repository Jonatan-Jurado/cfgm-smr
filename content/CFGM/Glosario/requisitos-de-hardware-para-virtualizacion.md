# Requisitos de hardware para virtualización
Condiciones necesarias que debe cumplir el equipo físico para poder realizar instalaciones de máquinas virtuales. El componente principal es el procesador, el cual debe tener integrada la tecnología que permite la virtualización. Los fabricantes de procesadores suelen proporcionar esta información en sus páginas web.
