# Técnica CHS
El sistema de direccionamiento físico conocido como Cilindro-Cabezal-[[Sector]] (CHS, *Cylinder-Head-Sector*) consiste en la localización de datos mediante la asignación de coordenadas numéricas. En esta técnica, se utiliza el número de cilindro, el número de cabezal (correspondiente a la cara del plato, empezando por el 0) y el número de Sector. La capacidad total de un disco bajo este sistema se determina multiplicando el número de cilindros por el número de caras, el número de sectores y el tamaño de cada Sector.
