# Instalación desatendida
Tipo de instalación que se realiza sin la intervención de un usuario, ya que todas las tareas están automatizadas. Se utiliza frecuentemente en entornos corporativos debido al ahorro de tiempo que conlleva. Estas instalaciones se basan en un archivo de respuesta (script o guion) que contiene todos los parámetros necesarios para configurar el sistema operativo.
