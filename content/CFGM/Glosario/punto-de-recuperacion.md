# Punto de recuperación
Una funcionalidad que permite devolver al sistema operativo a un estado estable previamente guardado, evitando la necesidad de formatear el disco y la consiguiente pérdida de configuración del sistema. Windows almacena copias automáticamente, añadiendo en cada una los cambios producidos y ofreciendo la opción de revertir el sistema a un punto anterior.

*   _Creación_: Es posible realizar puntos de recuperación de forma automática y manual. Se recomienda la creación automática, pero la manual es útil para mantener configuraciones específicas.
*   _Proceso de creación manual en Windows_: _Equipo → Propiedades → Protección del sistema → Crear_. Esto ejecuta el Asistente de Windows de creación de un nuevo punto de restauración.
*   _Almacenamiento_: Es posible almacenar el estado de ese punto de recuperación en dispositivos externos para una mayor flexibilidad y seguridad en el futuro.
*   _Consideraciones_: Es importante decidir previamente un punto de recuperación estable, ya que se trata de un proceso sensible. Revierte una gran cantidad de configuraciones de archivos importantes de las aplicaciones de Windows que, en caso de fallo, pueden dejar al sistema operativo muy dañado. Una vez recuperado, se vuelve a la configuración existente entonces en la máquina, incluida la información del usuario.
