# Documentación Técnica de Instalación
Es el registro detallado del [[Proceso]] de despliegue de una [[Máquina Virtual]]. Este documento debe dividirse en dos bloques: uno con las especificaciones del [[Sistema Anfitrión]] (procesador, RAM, [[Disco Duro]], arquitectura y [[Software]] de [[Virtualización]]) y otro con la configuración asignada a la Máquina Virtual (recursos asignados, clave de producto, credenciales de administrador y fecha de instalación). Es fundamental para la gestión de incidencias y el mantenimiento del sistema.
