# Gestión de Paquetes y Actualizaciones
Conjunto de procedimientos para el [[Mantenimiento del Software]]|mantenimiento del Software en [[Sistemas Operativos Libres]]. Incluye el uso de comandos como `[[Dpkg]] -l` para listar el Software instalado, `[[APT]]-get update` para sincronizar los índices de los repositorios y `APT-get dist-upgrade` para realizar una actualización completa de los paquetes del sistema y sus dependencias.
