# Código Unicode

Sistema de [[Codificación]] de caracteres de 16 bits diseñado para permitir la representación de una amplia variedad de sistemas de escritura, incluyendo alfabetos no latinos como el árabe, griego o japonés. Su mayor capacidad de bits en comparación con ASCII le permite albergar miles de caracteres adicionales, facilitando la internacionalización del [[Software]].
