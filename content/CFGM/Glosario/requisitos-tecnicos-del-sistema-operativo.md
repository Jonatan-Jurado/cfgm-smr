# Requisitos Técnicos del Sistema Operativo
Son las condiciones y especificaciones que un hardware o software debe cumplir para que un sistema operativo, o cualquier otro tipo de software o juego de ordenador, pueda ser instalado y funcionar de manera óptima. Se distinguen entre requisitos mínimos y recomendados.
