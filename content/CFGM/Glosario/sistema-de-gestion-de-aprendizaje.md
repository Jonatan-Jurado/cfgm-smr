# Sistema de gestión de aprendizaje
Un sistema de gestión de aprendizaje (LMS) permite a las organizaciones administrar y ofrecer cursos de formación en línea, realizar el seguimiento del progreso del aprendizaje y evaluar competencias.
Algunos ejemplos incluyen:
- _Moodle_
- _Canvas_
- _Blackboard_
