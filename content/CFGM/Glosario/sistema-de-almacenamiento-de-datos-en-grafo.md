# Sistema de almacenamiento de datos en grafo
Están diseñados para almacenar y consultar datos en forma de grafos, donde los nodos representan entidades y las aristas representan relaciones entre ellas.
Son útiles para aplicaciones que requieren:
- _Análisis de redes sociales_
- _Recomendaciones_
- _Detección de fraudes_
- _Análisis de redes_
Algunos ejemplos incluyen:
- _Neo4j_
- _Amazon Neptune_
- _Microsoft Azure Cosmos DB_
