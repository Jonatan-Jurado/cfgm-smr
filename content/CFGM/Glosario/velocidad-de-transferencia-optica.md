# Velocidad de Transferencia Óptica
La velocidad de las [[Unidades de CD]] se mide en múltiplos de una tasa base denominada "1x", que equivale a 150 KBps. Para conocer la velocidad real de transferencia de una unidad actual (por ejemplo, de 72x), se debe multiplicar dicho factor por la tasa base (72 * 150 KBps).
