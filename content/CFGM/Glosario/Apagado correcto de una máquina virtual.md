# Apagado correcto de una máquina virtual
Procedimiento recomendado para cerrar una máquina virtual de forma segura, similar a un equipo físico. Se realiza desde el menú de opciones dentro de la propia máquina virtual, seleccionando la opción "Apagar" o "Power off".
