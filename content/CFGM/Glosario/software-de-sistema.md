# Software de sistema
Programas que se encargan de ocultar la complejidad del hardware tanto al programador como al usuario final. A diferencia del software de aplicación, proporciona control sobre el hardware y sirve para controlar e interactuar con el sistema operativo.
- _Ejemplos_: sistemas operativos, herramientas de optimización y diagnóstico
