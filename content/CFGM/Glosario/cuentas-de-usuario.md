# Cuentas de Usuario
En la administración de sistemas operativos, las cuentas de usuario son perfiles que permiten gestionar el acceso y la seguridad de los diferentes individuos que utilizan un equipo. Como norma de seguridad fundamental, se recomienda el uso cotidiano de una cuenta de "[[Usuario Estándar]]" para evitar errores críticos o infecciones por virus, reservando la cuenta de "administrador" exclusivamente para tareas de configuración y mantenimiento que requieran privilegios elevados.
