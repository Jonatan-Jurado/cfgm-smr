# Fase de instalación

Representa el conjunto de etapas secuenciales necesarias para el despliegue correcto de un [[Sistema operativo]]. Se divide en cinco pasos críticos:
1. **Planificación:** Definición de instrucciones, previsión de errores y decisión entre actualizar o formatear.
2. **Preparación:** [[Configuración de la BIOS]]|Configuración de la BIOS/[[UEFI]] para establecer el [[Orden de Arranque]] (boot priority).
3. **Instalación:** Ejecución del asistente donde se define el tipo de instalación y el particionado del disco.
4. **Configuración:** Ajuste de parámetros [[POST]]-instalación como idioma, zona horaria, [[Cuentas de Usuario]]|cuentas de Usuario y red.
[[5]]. **Documentación:** Registro técnico de todo el [[Proceso]] para facilitar el mantenimiento futuro.
