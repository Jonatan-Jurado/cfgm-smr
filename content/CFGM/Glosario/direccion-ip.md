# Dirección IP
Identificador numérico asignado a un equipo en una red.
- _Obtener una dirección IP automáticamente_: Opción por defecto en Windows donde el router asigna una dirección IP al equipo, siendo la opción recomendada.
- _Especificar una dirección IP fija_: Opción para asignar manualmente una dirección IP específica al equipo. Todos los equipos de la red compartirán los tres primeros números, y el último será único para cada dispositivo.
