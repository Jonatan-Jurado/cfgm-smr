# Documentación Técnica de Software
Conjunto de guías y manuales proporcionados por el fabricante que detallan los requisitos de [[Hardware]], dependencias y pasos lógicos para la instalación de una aplicación. Es fundamental para garantizar el funcionamiento correcto del sistema y permite elegir entre instalaciones recomendadas (configuración estándar) o personalizadas (selección manual de componentes).
