# Gestión de memoria

Función del [[Sistema operativo]] encargada de distribuir de forma dinámica [[La Memoria]] RAM|Memoria RAM]]|la Memoria RAM|Memoria RAM]]]] entre los distintos procesos en ejecución. Debe asegurar que cada [[Proceso]] se ubique en una zona libre, controlar el acceso a recursos compartidos para evitar conflictos de lectura/escritura y resolver las colas de ejecución para optimizar el uso del [[Hardware]] en sistemas multiproceso.
