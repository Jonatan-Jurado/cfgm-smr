# Gestión de Inventario de Software
Consiste en el [[Proceso]] de mantenimiento y seguimiento de todos los programas instalados en el [[Sistema Operativo]]. En distribuciones basadas en Debian (como Ubuntu o Linux Mint), se utiliza el comando `[[DPKG]] -l` para obtener un listado detallado de todos los paquetes instalados. Este inventario es fundamental para la administración del sistema y para asegurar el correcto funcionamiento tras realizar cambios o actualizaciones.
