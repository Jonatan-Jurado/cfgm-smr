# Archivo de sistema NTFS

Conjunto de ficheros ocultos dentro del [[Volumen]] [[NTFS]] que permiten al [[Sistema operativo]] establecer definiciones de atributos para archivos y carpetas. Estos archivos son fundamentales para mantener la integridad del Volumen, gestionar los ID de los archivos y la cuota de disco.
