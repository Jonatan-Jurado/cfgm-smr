# Proceso de parada del sistema (Linux)
Procedimiento encargado de finalizar los servicios y programas que están en ejecución en un sistema Linux. Además, desmonta todas las unidades y dispositivos activos, así como el sistema de archivos.

Es necesario ejecutar este proceso siempre que se desee cambiar de nivel de ejecución o cuando exista una ejecución de procesos que sobrecarguen el sistema. Permite al administrador tener control sobre el mismo.
