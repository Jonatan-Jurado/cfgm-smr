# Selección de sistema operativo

[[Proceso]] analítico previo a la instalación donde se evalúa cuál es el [[Software]] que mejor se adapta a las necesidades del [[Usuario]]. Este análisis incluye la comprobación de compatibilidad de las aplicaciones requeridas, la distinción entre funciones de cliente o servidor, la elección de la edición específica (Home, PRO, Enterprise o Education) y la verificación de que el [[Hardware]] cumple con los requisitos mínimos y recomendados.
