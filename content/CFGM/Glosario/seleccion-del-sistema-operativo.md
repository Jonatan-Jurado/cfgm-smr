# Selección del Sistema Operativo
[[Proceso]] de elección del [[Software]] base que mejor se adapta a las necesidades del usuario. Implica analizar las aplicaciones que se van a utilizar para evitar incompatibilidades, decidir entre una versión de cliente o servidor, y verificar que las características del [[Hardware]] (requisitos mínimos y recomendados) soportan la versión elegida, como pueden ser las ediciones Home, Pro, Enterprise o Education de [[Windows]].
