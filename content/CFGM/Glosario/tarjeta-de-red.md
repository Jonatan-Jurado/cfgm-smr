# Tarjeta de red
Dispositivo que puede venir integrada en la placa base para mejorar el rendimiento, o ser instalada como una tarjeta externa en una ranura de expansión. Las tarjetas de red actuales utilizan luces de colores LED para informar de su funcionamiento, indicando si están conectadas y la velocidad a la que están trabajando. Cada tarjeta viene identificada por una dirección MAC o dirección física.

Los conectores que pueden utilizar estas tarjetas son:
- _RJ45_: Utilizado cuando la comunicación se hace mediante un cable con conectores que llevan el mismo nombre.
- _Wireless_: Utilizado cuando la comunicación es inalámbrica y sin cable, por lo que la tarjeta incorpora una antena para facilitar la comunicación (en el caso de los equipos portátiles, la antena es interna).
