# Sistema de gestión de recursos humanos
Un sistema de gestión de recursos humanos (HRMS) ayuda a gestionar aspectos como nóminas, reclutamiento, evaluaciones de desempeño, beneficios y desarrollo de empleados.
Algunos ejemplos incluyen:
- _Workday_
- _BambooHR_
- _ADP_
