# Archivo .vmx
Un archivo con extensión .vmx que se encuentra en el directorio de una máquina virtual, con el mismo nombre que esta. Funciona como un acceso directo a la máquina virtual y, al abrirlo con un editor de texto plano, es posible conocer su configuración.
