# Mantenimiento del Inventario de Software
Consiste en la revisión y gestión periódica del catálogo de programas instalados en un equipo. Esta tarea administrativa implica identificar aplicaciones obsoletas, incompatibles o innecesarias que consumen recursos del sistema. Un correcto mantenimiento incluye la reparación, modificación o desinstalación de dicho [[Software]] para garantizar el rendimiento óptimo y la seguridad del [[Sistema Operativo]].
