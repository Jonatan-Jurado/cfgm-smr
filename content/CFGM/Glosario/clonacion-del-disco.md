# Clonación del disco
Proceso que consiste en copiar el contenido completo de un disco duro o de una partición en otro disco o partición. Este proceso tiene múltiples funcionalidades:
- _Reinicio y restauración_: Permite instalar automáticamente el sistema operativo cada vez que se apaga el equipo, utilizando una imagen creada para asegurar un sistema siempre limpio.
- _Equipamiento de nuevas computadoras_: Facilita la instalación de múltiples ordenadores con los mismos programas, realizando la instalación en uno y luego clonando esa copia para el resto.
- _Actualización del disco duro_: Permite a un usuario cambiar su disco duro clonando el contenido del antiguo y copiándolo al nuevo.
- _Recuperación del sistema_: Posibilita restaurar una computadora a su configuración de fábrica.
- _Copia de seguridad de todo el sistema_: Es una forma de realizar una copia de seguridad completa del sistema.
