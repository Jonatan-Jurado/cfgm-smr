# Conversión hexadecimal-binario

[[Proceso]] de traducción directa en el que cada carácter de un número hexadecimal se convierte en una secuencia de cuatro dígitos binarios (bits). Esta correspondencia se mantiene tanto para los valores numéricos (0-9) como para los alfabéticos (A-F), donde A representa 1010 y F representa 1111.
