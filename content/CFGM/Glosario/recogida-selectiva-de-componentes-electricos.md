# Recogida selectiva de componentes eléctricos
Proceso orientado a la recogida gratuita de componentes eléctricos una vez que el usuario desea deshacerse de ellos. También rige normas para los fabricantes con el fin de facilitar la recogida selectiva de estos componentes en instalaciones autorizadas.
