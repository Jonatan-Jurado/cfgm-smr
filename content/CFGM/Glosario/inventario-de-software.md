# Inventario de software

Es el registro detallado de todas las aplicaciones y programas instalados en un [[Sistema informático]]. Este listado permite identificar programas obsoletos, evitar duplicidades de funcionalidades y verificar la compatibilidad con [[El Sistema operativo]]|el Sistema operativo. En [[Windows]], se gestiona principalmente desde el apartado de "[[Programas y características]]", donde se detalla el nombre, la fecha de instalación y el tamaño de cada [[Aplicación]].
