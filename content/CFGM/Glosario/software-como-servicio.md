# Software como servicio
En este tercer nivel de servicio en la nube, se proporciona al usuario aplicaciones y software bajo suscripción. Los usuarios pueden acceder a estas aplicaciones desde cualquier dispositivo con conexión a internet.
- _Ejemplos_: Google Workspace (antes G Suite), Microsoft Office 365, Salesforce.
