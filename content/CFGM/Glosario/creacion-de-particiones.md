# Creación de Particiones
Proceso de establecer nuevas particiones en un disco, especificando su tipo (primaria, extendida o lógica) y el espacio que ocuparán (tamaño).
- _Métodos_:
    - _CD de instalación_: Al instalar el sistema operativo.
    - _Orden Fdisk_: Utilizando la herramienta Fdisk en MS-DOS y Linux.
    - _Utilidad de administrador de discos_: La utilidad de Windows o la utilidad de discos de Ubuntu.
    - _Utilidades específicas_: Como Partition Magic y Partition Master para Windows, o Gparted para sistemas Linux.
