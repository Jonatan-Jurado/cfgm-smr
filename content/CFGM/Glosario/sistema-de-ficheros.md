# Sistema de ficheros (Linux)
Mecanismos de organización de datos que indican cómo se gestionan los ficheros dentro de las particiones en Linux. Pueden ser de diversos tipos:

*   _Basados en discos_: ext2, ext3, ext4, FAT, FAT32 o NTFS.
*   _Para la comunicación en red_: NFS, utilizado para compartir recursos entre equipos Linux.
