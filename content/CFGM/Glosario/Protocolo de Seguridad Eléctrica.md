# Protocolo de Seguridad Eléctrica
Normas preventivas críticas para el técnico de sistemas que incluyen: desconectar siempre el equipo antes de manipularlo, asegurarse de tener las manos totalmente secas para evitar descargas, utilizar los interruptores habilitados para la desconexión y garantizar una ventilación adecuada para evitar el [[Sobrecalentamiento]] de los componentes internos.
