# passwd
Comando utilizado en Linux para establecer o cambiar la contraseña de un usuario. Un usuario puede establecer su propia contraseña, pero para modificar la de otro usuario es necesario utilizar el comando siendo el usuario root. Por motivos de seguridad, la contraseña debe establecerse dos veces.
- _Sintaxis_: `passwd nombreUsuario`
