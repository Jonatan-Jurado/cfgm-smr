# Configuración de la placa

base. Software de base y de aplicación Una vez vistas todas las [[características de la placa]] base, lo único que nos queda por ver es el software de base (BIOS) y su [[gestor de arranque]]. La ROM BIOS la compone un conjunto de programas que se alojan en la memoria de un ordenador. Los chips ROM BIOS actuales emplean una memoria flash de tipo no volátil pero que puede leer y borrar eléctricamente. La BIOS proporciona un conjunto de rutinas que comprueban las comunicaciones Entrada/Salida. Estas rutinas son llamadas desde [[el sistema operativo]] a través de los drivers (controladores) para acceder al hardware. Además, es un programa de configuración implementado mediante sentencias a bajo a nivel. Tiene implementado un POST (conjunto de sentencias para las comprobaciones de los elementos hardware).
