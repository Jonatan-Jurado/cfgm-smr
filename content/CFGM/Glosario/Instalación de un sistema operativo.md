# Instalación de un sistema operativo
Proceso fundamental que permite establecer un sistema operativo en un dispositivo para que este pueda funcionar. Se compone de cinco fases principales:
- _Planificación_: Es conveniente reflexionar sobre cómo se realizará la instalación y cuáles serán las instrucciones a seguir. Implica conocer el estado actual del sistema para decidir si se va a actualizar o formatear.
- _Preparación_: Consiste en configurar el ordenador para recibir la instalación, lo que generalmente implica acceder a la BIOS para configurar la opción de arranque e indicar el dispositivo que se usará.
- _Instalación_: Durante esta fase se deben indicar algunas configuraciones específicas, como el tipo de instalación o la partición que se va a utilizar.
- _Configuración_: Una vez instalado el sistema operativo, se deben aceptar las licencias y configurar parámetros básicos como la zona horaria, el idioma, el nombre del equipo, el usuario administrador y la administración de red.
- _Documentación_: Es necesario registrar toda la información del proceso de instalación para dejar constancia de lo realizado y facilitar un mejor mantenimiento del sistema.
