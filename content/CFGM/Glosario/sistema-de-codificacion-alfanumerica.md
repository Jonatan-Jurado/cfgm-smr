# Sistema de Codificación Alfanumérica
Un sistema de codificación alfanumérica se emplea para la representación de datos no numéricos o alfanuméricos en sistemas informáticos.

- _Ejemplos_: Los códigos más conocidos incluyen ASCII, EBCDIC o Unicode.
