# Programador de tareas
Herramienta de Windows encargada de ejecutar comandos o acciones predefinidas en el momento y la frecuencia establecidos por el usuario.
- _Permisos_: Requiere permiso de administrador para crear tareas, pero permite cambiar la configuración para el usuario actual sin ellos.
- _Proceso de creación de una tarea básica_:
    - _Acceso_: Clicar en Panel de control → Sistema y seguridad → Herramientas administrativas → Programar tareas.
    - _Inicio_: Hacer clic en el menú Acción → Crear tarea básica.
    - _Configuración_:
        - _Nombre y descripción_: Identificación de la tarea.
        - _Frecuencia de inicio_: Diariamente, semanalmente, mensualmente, etc.
        - _Inicio, hora y repetición_: Detalles temporales de la ejecución.
        - _Acción a realizar_: Elegir el programa o script que desea iniciar.
