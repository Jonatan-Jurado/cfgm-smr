# Memory Stick
Formato de memoria fabricado por la multinacional Sony para la compatibilidad con todos sus dispositivos (cámaras de fotos, cámaras de vídeo, reproductores). Ha sufrido varias actualizaciones y mejoras, pasándose a llamar Memory Stick Pro, y la última versión en el mercado es la Memory Stick Pro Duo.
