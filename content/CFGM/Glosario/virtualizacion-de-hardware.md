# Virtualización de hardware

Capacidad técnica del procesador ([[CPU]]) para ejecutar múltiples sistemas operativos de forma eficiente y aislada. Es un requisito crítico para ejecutar sistemas operativos invitados de 64 bits (x86-64) sobre hipervisores. Si esta función no está habilitada en la [[BIOS]]/[[UEFI]] o el procesador no es compatible, la [[Máquina virtual]] puede mostrar errores de [[Kernel]] o denegar el inicio del [[Sistema operativo]] invitado.
