# GNU Linux
Combinación del [[Sistema Operativo]] [[GNU]] con el núcleo ([[Kernel]]) Linux, desarrollado por Linus Torvalds. Mientras que GNU aporta las herramientas de usuario y el entorno, Linux gestiona el [[Hardware]]. Está escrito principalmente en [[Lenguaje C]] y permite trabajar tanto en [[Modo Consola]] (CLI) como mediante interfaz gráfica (GUI).
