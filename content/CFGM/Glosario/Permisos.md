# Permisos
Son una serie de reglas de acceso para las operaciones de lectura, escritura y ejecución que garantizan la seguridad en el sistema de archivos. Al contrario que los atributos, estos se establecen para cada tipo de usuario.

Los permisos sobre directorios y archivos son diferentes y varían según el tipo de sistema operativo. Permiten a un usuario controlar quién puede utilizar un fichero y qué operaciones (lectura, escritura, ejecución) puede realizar sobre él.
