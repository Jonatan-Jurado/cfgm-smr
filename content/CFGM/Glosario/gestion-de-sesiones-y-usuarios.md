# Gestión de Sesiones y Usuarios
Capacidad de los sistemas operativos modernos, como [[Windows]] 10, para administrar múltiples perfiles de usuario de forma simultánea. Cada usuario dispone de sus propios [[Directorios]], configuración de escritorio y aplicaciones instaladas, manteniendo la privacidad de sus archivos mientras permite la opción de compartir documentos. En este ámbito, el sistema ofrece diversas opciones de finalización de sesión: cerrar sesión, suspender (estado de bajo consumo), apagar o reiniciar.
