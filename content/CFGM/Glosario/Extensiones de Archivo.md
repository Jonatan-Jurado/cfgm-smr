# Extensiones de Archivo
Sufijo situado al final del nombre de un [[Archivo]], precedido por un punto, que indica al [[Sistema Operativo]] el formato del Archivo y qué [[Aplicación]] debe utilizarse para abrirlo. Por ejemplo, la extensión .txt identifica archivos de texto plano. Cambiar la extensión de forma manual puede provocar que el Archivo sea ilegible para las aplicaciones asociadas.
