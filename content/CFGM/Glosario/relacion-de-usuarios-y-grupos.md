# Relación de Usuarios y Grupos
Es la configuración que permite establecer vínculos entre las [[Cuentas de Usuario]] y los grupos creados en el sistema. Esta organización facilita la administración de [[Permisos]], permitiendo indicar con precisión a qué grupo pertenece cada usuario para controlar quién puede ver, modificar o eliminar archivos.
