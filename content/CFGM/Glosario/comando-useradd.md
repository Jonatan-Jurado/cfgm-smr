# Comando useradd
Comando utilizado para añadir nuevos usuarios al sistema. Permite diversas opciones de configuración como `-g` (definir el grupo principal), `-d` (establecer la [[Ruta]] del [[Directorio]] home), `-m` (crear el Directorio personal si no existe) y `-s` (especificar la [[Shell]] por defecto, generalmente `/bin/bash`).
