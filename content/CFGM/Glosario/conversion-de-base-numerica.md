# Conversión de base numérica

Procedimiento matemático para transformar un número de un sistema de representación a otro. Para pasar de decimal a otra base, se dividen sucesivamente los números enteros entre la base de destino (tomando el último cociente y los restos) o se multiplican las partes decimales por dicha base hasta que la parte decimal desaparezca o se alcance la precisión deseada.
