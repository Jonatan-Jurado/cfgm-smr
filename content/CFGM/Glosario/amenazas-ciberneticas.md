# Amenazas Cibernéticas
Acciones cuyo objetivo es comprometer la confidencialidad, integridad y disponibilidad de la información y los sistemas. Entre los numerosos tipos de amenazas, se incluyen:
- _Ataques de hackers_: acciones que buscan vulnerar las redes y sistemas informáticos de una organización para obtener acceso no autorizado u obtener el control de los archivos digitales.
- _Malware o programas malignos_: código creado para corromper un sistema informático.
- _Ransomware_: técnica utilizada por ciberdelincuentes para tomar el control del equipo o sistema y «secuestrarlo» con la intención de extorsionar al usuario.
- _Phishing_: técnica que usan los ciberdelincuentes para obtener datos de los usuarios de forma fraudulenta.
