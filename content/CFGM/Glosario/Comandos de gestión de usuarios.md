# Comandos de gestión de usuarios
Conjunto de instrucciones utilizadas en Linux para administrar cuentas de usuario. Solo el usuario root puede realizarlos, o cualquier usuario con la capacidad de usar `sudo` delante de cada comando. Permiten controlar los archivos y programas a los que los usuarios tendrán permiso de acceso y qué tipo de acciones podrán realizar.
