# Conversión entre Octal y Hexadecimal
No existe un método directo cómodo para pasar de octal a hexadecimal o viceversa. Para realizar esta operación, se utiliza el [[Sistema Binario]] como paso intermedio:
1. Se convierte el número original (octal o hexadecimal) a binario.
2. El resultado binario se vuelve a agrupar según la base de destino (en grupos de 4 para hexadecimal o grupos de 3 para octal).
