# Recuperación del Sistema Operativo
Proceso de restaurar un sistema operativo a un estado funcional, especialmente en caso de fallo o problemas.

- _Uso de copias de seguridad_: La opción más fácil y rápida, utilizando el sistema de copias de seguridad del disco duro y archivos importantes.
- _Modo rescate de Linux_: Es necesario si no se tienen copias de seguridad realizadas.
