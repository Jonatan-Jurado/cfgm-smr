# Características del sistema operativo huésped (documentación MV)
Los apartados que deben definirse para el sistema operativo huésped en la documentación técnica de una máquina virtual. Algunos parámetros pueden no aplicarse dependiendo del tipo de sistema operativo (ej. clave de producto en SO libre).
- _Nombre_
- _Versión_
- _Arquitectura_
- _Clave del producto_
- _Fecha y hora de instalación_
- _Usuario administrador_
- _Contraseña_
- _Licencias instaladas_
- _Observaciones_
