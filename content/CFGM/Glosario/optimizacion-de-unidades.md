# Optimización de unidades
Proceso que se utiliza para compactar las aplicaciones de Windows y ahorrar espacio en el disco duro.

-   _Beneficios_: Reduce considerablemente el espacio que usan las aplicaciones y mejora la carga de inicio del sistema operativo.
-   _Recomendación previa_: Realizar una copia de seguridad de los archivos antes de este proceso, ya que pueden dañarse si hay algún problema durante la ejecución.
