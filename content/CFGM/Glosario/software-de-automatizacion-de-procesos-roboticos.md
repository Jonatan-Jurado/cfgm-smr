# Software de Automatización de Procesos Robóticos
Software que permite automatizar tareas repetitivas y basadas en reglas utilizando robots de software. Estos robots pueden imitar las acciones humanas en sistemas informáticos para realizar tareas como la entrada de datos, la extracción de información o la generación de informes.
