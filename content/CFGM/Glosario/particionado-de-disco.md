# Particionado de disco
Proceso de dividir un disco duro en una o varias secciones lógicas llamadas particiones. Es un paso fundamental, ya que los discos duros suelen adquirirse sin ningún tipo de formato. La creación de particiones es necesaria para poder establecer un sistema de archivos y organizar los datos. Las particiones se pueden crear de forma independiente según se necesiten.
