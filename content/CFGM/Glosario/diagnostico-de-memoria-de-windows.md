# Diagnóstico de Memoria de Windows
Herramienta integrada en el sistema operativo Windows para realizar la comprobación del estado de las memorias RAM del ordenador. A través de su interfaz gráfica se elige en qué momento se quiere realizar la comprobación. Al reiniciar el equipo, comienza el diagnóstico de las memorias, el cual concluye con un informe final sobre su estado.
