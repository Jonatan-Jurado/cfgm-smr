# Planificación de procesos

Es el método o criterio que utiliza [[El Sistema operativo]]|el Sistema operativo para determinar el orden y el tiempo que cada [[Proceso]] utilizará el procesador. Busca un equilibrio entre diversos factores como la imparcialidad, la eficiencia del [[Hardware]], la productividad del sistema y la predecibilidad de los tiempos de respuesta.
