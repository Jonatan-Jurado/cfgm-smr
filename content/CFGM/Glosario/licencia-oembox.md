# Licencia OEMBOX
Tipo de licencia de Windows cuyas características principales son:
- _Componentes_: Se compone de una etiqueta con el holograma de Windows y un DVD para la instalación.
- _Uso y asociación_: Solo permite ser activada en una instalación y usada en un único equipo, ya que está asociada al hardware de este.
- _Validez_: Deja de ser válida si se modifica el hardware de la máquina.
- _Virtualización_: Permite la virtualización, aunque se requiere una licencia por cada máquina virtual con este sistema operativo.
