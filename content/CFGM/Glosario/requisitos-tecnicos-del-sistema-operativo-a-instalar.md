# Requisitos técnicos del sistema operativo a instalar
Especificaciones mínimas que debe cumplir un equipo para poder instalar y ejecutar un sistema operativo.
- _Sistemas operativos libres_: Sus requisitos suelen ser menores que los de uno propietario, especialmente si no se instala su entorno gráfico.
- _Distribuciones de Linux_: Cada una tiene sus propios requisitos mínimos y recomendados, que dependen de sus funcionalidades.
- _Ejemplo de requisitos mínimos para Ubuntu Desktop 20.04 LTS_:
    - _Procesador_: 1 GHz
    - _Memoria RAM_: 1,5 GB
    - _Disco duro_: 7 GB
