# Permiso de archivo

Conjunto de reglas de acceso que regulan las [[Operaciones]] de lectura, escritura y ejecución sobre los elementos del [[Sistema de archivos]]. Su objetivo principal es garantizar la seguridad, permitiendo que estas reglas se establezcan de forma específica para diferentes usuarios o grupos, de modo que el propietario pueda restringir o permitir acciones según sea necesario.
