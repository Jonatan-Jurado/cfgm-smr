# Mantenimiento del software
Proceso periódico de corrección de errores y mejoras en la estabilidad de un sistema operativo o aplicación. Se considera una de las etapas del ciclo de vida de un software y se lleva a cabo normalmente una vez que el software ha sido puesto en ejecución, implicando un seguimiento detallado de su evolución.
