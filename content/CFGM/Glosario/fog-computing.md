# Fog computing
Es una arquitectura informática descentralizada que permite que los datos, las comunicaciones y las aplicaciones se distribuyan entre la fuente de datos y la nube. No está concebida como una alternativa a la informática en la nube, sino como un complemento para optimizar el rendimiento.

- _Objetivo principal_: reducir la latencia y mejorar el rendimiento.
- _Beneficios_:
    - _Procesamiento de datos en tiempo real_: permite el procesamiento de datos en tiempo real y en combinación con otras fuentes de datos, lo que le otorga una mayor eficacia.
- _Inconvenientes_:
    - _Infraestructura compleja_: requiere una infraestructura distribuida que abarca una variedad de dispositivos y sistemas, lo que hace realmente compleja la integración y la gestión de sus componentes.
    - _Costes elevados_: los costes de esta infraestructura son mayores.
