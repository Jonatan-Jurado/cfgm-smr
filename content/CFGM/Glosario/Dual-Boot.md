# Dual-Boot
Configuración que permite instalar dos o más sistemas operativos en el mismo aparato. Consiste en repartir el espacio físico del disco duro entre los sistemas operativos, especificando cuánto almacenamiento tendrá cada uno. Es cada vez más habitual que los usuarios deseen tener más sistemas operativos además de los preinstalados (como Windows o Mac OS).
- _Consideración_: Se pueden instalar tantos sistemas operativos como unidades lógicas permita tener el disco duro.
