# Archivo de respuesta
Un archivo (también conocido como script o guion) que contiene todos los parámetros necesarios para realizar cualquier configuración que ofrezca respuestas a las preguntas planteadas por el sistema operativo durante un proceso de instalación desatendida. Permite automatizar las tareas sin intervención del usuario.
