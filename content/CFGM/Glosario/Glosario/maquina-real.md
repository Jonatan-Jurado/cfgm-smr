# Máquina real
El sistema informático que se tiene físicamente, el cual tiene instalado un sistema operativo sobre el que trabaja el usuario.

A veces hay operaciones que no se deben realizar en ella, ya sea porque la configuración no lo permite o porque estas puedan interferir con el resto de las aplicaciones del sistema. El sistema operativo de la máquina real se considera "anfitrión".
