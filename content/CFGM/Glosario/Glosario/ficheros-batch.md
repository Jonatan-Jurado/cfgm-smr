# Ficheros Batch
Archivos de procesamiento por lotes con extensión `.bat` que contienen una secuencia de comandos ejecutables por el Símbolo del sistema. Se utilizan principalmente para la [[Automatización de Tareas]] administrativas, permitiendo el uso de variables, pausas de ejecución y la gestión de la salida de texto mediante el comando `echo`.
