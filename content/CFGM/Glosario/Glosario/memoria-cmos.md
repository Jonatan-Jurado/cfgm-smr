# Memoria CMOS
Contiene almacenada la configuración del sistema, como la fecha y hora, y la información básica de todos los recursos que componen el sistema. Esta memoria se alimenta de una pila o batería necesaria para que el ordenador funcione sin necesidad de estar conectado a corriente.
