# Herramientas para el montaje
Conjunto de elementos necesarios o recomendados para el proceso de montaje de un equipo informático.

- _Destornillador de estrella_: (si es magnetizado, mejor)
- _Pinzas_: para elementos pequeños
- _Tenazas_
- _Pulsera antiestática_: pulsera colocada en la muñeca que va unida a unas pinzas para disminuir riesgos
- _Bote de pasta térmica_: usado para disminuir la temperatura generada por el procesador
- _Cinta aislante_
- _Linterna_
- _Bridas_
- _Polímetro_: para subsanar cualquier avería producida en el momento del montaje
