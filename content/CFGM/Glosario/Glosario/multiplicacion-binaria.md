# Multiplicación Binaria
Es una operación aritmética realizada en el [[Sistema Binario]] que sigue reglas similares a la multiplicación decimal. Los productos básicos son: 0 x 0 = 0; 0 x 1 = 0; 1 x 0 = 0; y 1 x 1 = 1. En la práctica, multiplicar por un número binario implica realizar desplazamientos y sumas sucesivas de los operandos.
