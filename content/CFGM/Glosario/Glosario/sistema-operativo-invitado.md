# Sistema operativo invitado
Un sistema operativo que se ejecuta dentro de una máquina virtual, alojado por un sistema operativo anfitrión. Puede compartir recursos (como memorias USB o discos físicos) con el sistema anfitrión si se configura previamente en el software de virtualización.
