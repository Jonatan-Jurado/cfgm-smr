# Movilidad Funcional
Es un tipo de modificación del contrato de trabajo que permite alterar las funciones que realiza el trabajador, generalmente mediante acuerdo de las partes.

Según si las tareas asignadas se encuentran dentro o fuera del grupo profesional del trabajador, la movilidad funcional puede clasificarse en:
- _Horizontal_: Se produce cuando el cambio de funciones tiene lugar dentro del mismo rango profesional. Esta modificación no requiere justificación ni formalidad y no tiene limitación temporal.
- _Vertical_: Ocurre cuando el cambio de funciones se realiza fuera del rango profesional del trabajador. En este caso, el empresario debe justificar la modificación por causa organizativa o técnica y mantenerla exclusivamente durante el tiempo necesario.
