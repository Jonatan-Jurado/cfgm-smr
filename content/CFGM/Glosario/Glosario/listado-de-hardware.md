# Listado de hardware

Herramienta integrada en Linux diseñada para proporcionar información detallada sobre todos los componentes físicos instalados en el equipo. Mediante la orden [[Lshw]], el sistema devuelve un informe completo que puede ser exportado a formatos como HTML o visualizado mediante una [[Interfaz]] gráfica si se utiliza la opción -gtk.
