# Arranque dual
Mecanismo para tener dos o más sistemas operativos en el mismo dispositivo físico, sin que haya que crear una máquina virtual.

Cuando el usuario enciende el ordenador, el boot de arranque le permite elegir el sistema operativo en el que quiere trabajar. El arranque dual obliga a realizar una partición real en el disco duro, por lo que se debe destinar un espacio físico a cada sistema operativo. Presenta más inconvenientes que la virtualización.
