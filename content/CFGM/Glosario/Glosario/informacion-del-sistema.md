# Información del sistema
Aplicación de Windows que permite visualizar fácilmente el listado completo del hardware conectado al equipo y su estado. Es útil para labores de mantenimiento, comprobación de configuración o detección de necesidades de reparación.
- _Función principal_: Mostrar el listado completo del hardware instalado.
- _Comprobación de estado_: Permite observar el estado de los dispositivos en una columna asociada.
- _Acceso_: Se ejecuta con el comando `msinfo32`.
