# Usuario Estándar
Es cualquier usuario del equipo. Como hábito de seguridad, se debe utilizar el sistema siempre con un usuario estándar y dejar la cuenta de administrador para ocasiones determinadas, lo que ayuda a evitar la mayor parte de los errores que se pueden ocasionar, como la infección del equipo por un virus.
