# Error Operating System Not Found
Es un error de arranque que indica que el [[Software]] de [[Virtualización]] no ha podido cargar un [[Sistema Operativo]]. Generalmente, este fallo ocurre porque no se ha especificado correctamente la [[Ruta]] de acceso a la [[Imagen ISO]] del sistema o porque el [[Proceso]] de instalación en el disco duro virtual no se ha completado con éxito.
