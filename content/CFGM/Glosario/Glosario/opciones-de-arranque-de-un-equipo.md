# Opciones de arranque de un equipo
Las distintas configuraciones y dispositivos desde los cuales un equipo informático puede iniciar su funcionamiento. Estas opciones se configuran en el programa de la BIOS, específicamente en el apartado BOOT, para determinar el orden de búsqueda del lugar donde reside el sistema operativo.

Dispositivos de arranque mencionados:
- _Desde CD-ROM_: Permite arrancar el equipo utilizando un CD-ROM que contiene la imagen del sistema operativo y programas.
- _Live CD_: Una distribución de sistema operativo en CD-ROM que es autoejecutable, facilitando un arranque y uso visual al usuario.
- _Memoria USB_: Permite arrancar un equipo desde una unidad USB. Esta posibilidad se popularizó cuando los fabricantes de portátiles dejaron de incluir dispositivos de CD-ROM. Para crear una memoria USB con un sistema operativo, se requiere un programa informático (para Windows) o secuencias de comandos (para Linux).
