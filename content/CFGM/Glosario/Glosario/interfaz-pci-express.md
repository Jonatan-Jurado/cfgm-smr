# Interfaz PCI Express
Estándar actual de bus de expansión para ordenadores, que sustituyó a los antiguos [[PCI]] y [[AGP]]. Es una interfaz de alta velocidad utilizada para conectar diversos dispositivos, siendo el [[Zócalo]] estándar para la instalación de tarjetas gráficas modernas.
