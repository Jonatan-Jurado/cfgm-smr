# Modo rescate

Es un método de arranque de emergencia utilizado para reparar un [[Sistema operativo]] Linux que presenta fallos críticos. Se puede acceder a él mediante medios externos como CD-ROM, [[DVD]] o dispositivos flash USB. Al iniciar el comando `linux rescue dd`, el sistema descarga los [[Controladores]] necesarios y busca automáticamente una imagen estable en el disco para montarla en la [[Ruta]] `/mnt/sysimage`, permitiendo así la restauración y corrección de errores del sistema.
