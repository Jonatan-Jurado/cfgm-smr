# Compartir carpetas
Una funcionalidad de los softwares de virtualización que permite compartir información y recursos entre el sistema operativo anfitrión y el invitado.

Para configurar la compartición de carpetas, se deben seguir los siguientes pasos:
1. _Crear o seleccionar un directorio/carpeta_: en el sistema anfitrión para ser compartido.
2. _Agregar la ruta de esta carpeta_: en la configuración del software de virtualización.
3. _Habilitar el modo Compartir carpetas_: en el software de virtualización.

Una vez configurado, permite arrastrar archivos entre los sistemas operativos y agiliza la transferencia y el acceso a recursos.
