# Conversión de Decimal a Otras Bases
[[Proceso]] matemático para transformar un valor en base 10 a cualquier otro sistema (binario, octal, etc.). El procedimiento varía según la parte del número:
1. **Parte entera:** Se realizan divisiones sucesivas del número entre la base de destino hasta que el cociente sea menor que la base. El resultado se forma con el último cociente y los restos obtenidos en orden inverso.
2. **Parte decimal:** Se multiplica la fracción por la base de destino sucesivamente hasta que la parte decimal desaparezca o se alcance la precisión deseada. Se toman las partes enteras resultantes de cada operación para formar el nuevo número.
