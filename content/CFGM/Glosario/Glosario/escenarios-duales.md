# Escenarios Duales
Configuración que permite tener más de un sistema operativo instalado en el mismo ordenador. Al iniciar la máquina, se muestra una pantalla previa al arranque que permite al usuario elegir cuál de los sistemas operativos desea iniciar.

- _Funcionamiento_: La BIOS carga el gestor de arranque, el cual detecta los múltiples sistemas operativos y presenta las opciones al usuario.
- _Limitación_: Solo se puede utilizar un sistema operativo a la vez. Si se desea cambiar, es necesario reiniciar la máquina y seleccionar el sistema deseado en la pantalla de arranque dual.
