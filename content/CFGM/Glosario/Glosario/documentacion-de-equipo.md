# Documentación de equipo

Registro técnico detallado que recopila las características fundamentales de la parte física ([[Hardware]]) y lógica ([[Software]]) de un [[Sistema informático]]. En el ámbito del Hardware, debe incluir la referencia, marca, modelo, procesador, [[Memoria]] RAM|Memoria RAM]], [[Dispositivos de Almacenamiento]], [[Tarjeta gráfica]] y de red. Respecto al Software, se debe registrar la fecha de instalación, tipo, versión, arquitectura, licencias y usuarios administradores. Esta documentación es vital para el [[Mantenimiento preventivo]] y correctivo, permitiendo consultar errores previos y soluciones aplicadas para agilizar futuras reparaciones.
