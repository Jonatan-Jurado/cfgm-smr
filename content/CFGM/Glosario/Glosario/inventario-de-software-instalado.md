# Inventario de software instalado
Proceso de comprobación y listado de todas las aplicaciones o programas software que existen dentro de un equipo. Este proceso es útil para gestionar una lista extensa de programas, evitar la duplicidad de funcionalidades al realizar nuevas instalaciones, y para identificar software obsoleto o sin soporte.
- _Ubicación en Windows_: Se realiza en el apartado "Programas y características".
- _Información detallada_: Se listan las aplicaciones con su fecha de instalación y tamaño.
- _Métodos de obtención_: Puede obtenerse a través de la interfaz gráfica en "Programas y características" o mediante la consola de comandos de Windows (donde la desinstalación puede ser más tediosa al no contar con una interfaz gráfica).
