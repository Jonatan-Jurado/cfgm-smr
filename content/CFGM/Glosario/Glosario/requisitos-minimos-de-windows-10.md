# Requisitos Mínimos de Windows 10 (32 bits)
Especificaciones de hardware necesarias para poder instalar la versión de 32 bits del sistema operativo Windows 10.

- _Procesador_: 1 GHz o superior.
- _Memoria RAM_: 1 GB.
- _Espacio libre en disco_: 16 GB.
- _Tarjeta gráfica_: Procesador gráfico DirectX® 9 con el Modelo de controladores de pantalla de Windows (WDDM) o un controlador superior.
