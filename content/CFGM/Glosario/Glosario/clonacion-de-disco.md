# Clonación de disco
Proceso de copiar el contenido completo de un disco duro o de una partición a otro. Se utiliza para diversas funcionalidades:
- _Restaura el sistema operativo automáticamente_: Permite tener un sistema limpio al apagar y encender el equipo, utilizando una imagen creada previamente.
- _Equipamiento de nuevas computadoras_: Facilita la instalación de los mismos programas en varios ordenadores, realizando una instalación en uno y clonando la copia al resto.
- _Actualización del disco duro_: Permite a un usuario cambiar su disco duro clonando el contenido del antiguo y copiándolo al nuevo.
- _Recuperación del sistema_: Restaura una computadora a su configuración de fábrica.
- _Copia de seguridad de todo el sistema_.
- _Software ejemplo_: Clonezilla es un software libre para realizar la clonación de discos.
