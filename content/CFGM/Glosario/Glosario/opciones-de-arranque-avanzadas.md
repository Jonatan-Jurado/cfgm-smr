# Opciones de Arranque Avanzadas
Es un menú de recuperación de [[Windows]] que permite iniciar el sistema en estados especiales para diagnosticar y solucionar fallos. En versiones anteriores a Windows 10, se accede habitualmente pulsando la tecla F8 durante el encendido. Incluye herramientas para reparar el inicio, habilitar modos de depuración o deshabilitar [[Controladores]] problemáticos.
