# Fuego de Clase A
Corresponde a los incendios que involucran materiales orgánicos sólidos, como madera, papel, telas o plásticos comunes. El combustible es el que define esta clase.

_Agentes extintores indicados_:
- _Agua a chorro_
- _Agua pulverizada_ (más efectiva que la base de agua)
- _Polvo polivalente_
- _Anhídrido carbónico (CO₂)_ (con menos efectividad)
