# Solución de averías
Proceso que se lleva a cabo una vez identificado un fallo en un equipo informático. Si la avería es provocada por un elemento físico conectado, normalmente se opta por el intercambio de este por una pieza nueva, ya que los elementos hardware rara vez se reparan.

Las soluciones comunes incluyen:
- _Problemas de conexión_: Verificar y asegurar todas las conexiones.
- _Medición de tensión_: Usar un polímetro para verificar el suministro eléctrico.
- _Sustitución de placa base_: En caso de fallo en este componente crítico.
