# Archivos Batch
También conocidos como ficheros por lotes, son archivos de texto plano con extensión `.bat` que contienen una secuencia de comandos del sistema. Se utilizan para automatizar tareas administrativas repetitivas mediante el Símbolo del sistema. Su estructura suele incluir comandos como `echo off` (para ocultar la salida de comandos) y `@pause` (para detener la ejecución y revisar resultados).
