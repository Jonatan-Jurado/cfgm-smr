# Desactivación de RunFullMemoryDiagnostic
Proceso que implica desactivar la tarea programada del sistema `RunFullMemoryDiagnostic` a través del `Programador de Tareas`.

-   _Ruta en Windows_: Programador de Tareas → Biblioteca del Programador de tareas → Microsoft → Windows → Memory Diagnostic.
-   _Efecto_: Reduce el número de veces que el sistema compacta la memoria y aumenta el rendimiento del equipo.
