# Automatización de Tareas y Guiones
Uso de scripts o archivos de comandos que permiten ejecutar secuencias de órdenes de forma automática y programada. En administración de sistemas, se emplean para optimizar procesos repetitivos como copias de seguridad, mantenimiento de registros o configuraciones masivas del entorno.
