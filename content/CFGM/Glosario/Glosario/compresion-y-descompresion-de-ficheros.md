# Compresión y descompresión de ficheros
La compresión de ficheros es el proceso de reducir su peso para que ocupe menos espacio, sin perder información. La descompresión es el proceso inverso.

Para realizar estas operaciones mediante la interfaz gráfica, es necesario instalar un software como WinRAR o 7zip. También es posible realizarlas mediante comandos.
