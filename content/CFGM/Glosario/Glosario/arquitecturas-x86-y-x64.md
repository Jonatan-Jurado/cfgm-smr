# Arquitecturas x86 y x64
Estos términos definen el tipo de procesamiento de datos de un ordenador. La arquitectura x86 se refiere a sistemas de 32 bits, los cuales solo pueden ejecutar [[Software]] diseñado específicamente para esa arquitectura. Por otro lado, la arquitectura x64 corresponde a sistemas de 64 bits, que tienen la ventaja de ser retrocompatibles, permitiendo la instalación y ejecución tanto de programas de 32 bits como de 64 bits.
