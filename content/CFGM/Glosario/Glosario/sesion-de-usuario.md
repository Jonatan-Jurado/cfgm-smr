# Sesión de usuario
En sistemas operativos como Windows 10, es la capacidad de registrar múltiples usuarios, donde cada uno puede tener sus propios directorios y programas instalados, aunque también es posible que compartan documentos. El proceso de apagado del sistema incluye opciones relacionadas con la sesión, como _Cerrar sesión_, _Suspender_, _Apagar_ y _Reiniciar_.
