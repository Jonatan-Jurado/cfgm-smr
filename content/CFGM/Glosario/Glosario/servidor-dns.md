# Servidor DNS

Servidor encargado de traducir nombres de dominio legibles para humanos (como una dirección web) en direcciones IP comprensibles por las máquinas. Su configuración es vital para la navegación por [[Internet]], pudiendo obtenerse automáticamente del proveedor de servicios o especificarse manualmente para mejorar la velocidad o seguridad de la resolución de nombres.
