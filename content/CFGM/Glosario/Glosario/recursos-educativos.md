# Recursos Educativos
Componentes del entorno personal de aprendizaje que proporcionan el conocimiento esencial para la carrera, comparables a los libros de referencia en una caja de herramientas.
- _Cursos en línea_: Inscripción en plataformas como Coursera o Udemy para adquirir conocimientos especializados.
- _Certificaciones_: Actúan como credenciales visibles, como la certificación Project Management Professional (PMP), para destacar entre los candidatos.
- _Lecturas relevantes_: Libros y artículos sobre el campo para mantenerse actualizado sobre tendencias y mejores prácticas.
