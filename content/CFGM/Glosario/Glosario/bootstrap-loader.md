# Bootstrap Loader

Programa especializado encargado de buscar y cargar el [[Sistema operativo]] en la [[Memoria]] RAM|Memoria RAM]]. Se ejecuta inmediatamente después de que la [[BIOS]] finaliza las comprobaciones iniciales, localizando el [[Sector]] de Arranque|Sector de arranque]] ([[MBR]]) en las [[Unidades de Almacenamiento]] configuradas para iniciar el [[Software]] de control del equipo.
