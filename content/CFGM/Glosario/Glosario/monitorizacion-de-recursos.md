# Monitorización de Recursos
Es el proceso de seguimiento en tiempo real del uso de los componentes físicos del sistema (CPU, memoria RAM, disco duro y GPU) por parte de las máquinas virtuales. Esta tarea es fundamental para asegurar que los recursos asignados sean adecuados y no perjudiquen el rendimiento global del equipo anfitrión. En sistemas Windows, se puede realizar mediante herramientas nativas como el Monitor de recursos.
