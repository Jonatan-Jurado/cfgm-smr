# Error de Arquitectura de CPU
Fallo que se manifiesta con el mensaje "This [[Kernel]] requires an x86-64 [[CPU]]". Este error ocurre habitualmente por dos motivos: intentar ejecutar un [[Sistema Operativo]] de 64 bits en un procesador físico de 32 bits, o que el procesador físico no tiene habilitadas las funciones de [[Virtualización]] por [[Hardware]] en la [[BIOS]]/[[UEFI]] del equipo.
