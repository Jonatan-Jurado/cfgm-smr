# Operaciones con Particiones
Conjunto de acciones importantes que se pueden realizar al trabajar con particiones en un sistema.
- _Creación_: Consiste en indicar el tipo (primaria, extendida o lógica) y el tamaño que va a ocupar la partición.
- _Eliminación_: Proceso de borrar una partición, lo que también elimina todos los datos que esta contenga.
- _Redimensionamiento_: Permite modificar el tamaño de una partición sin perder los datos que contenga, siempre que haya espacio suficiente en el disco.
- _Ocultar/Mostrar_: Función para controlar la visibilidad de particiones a las que no se puede tener acceso desde la partición de arranque del sistema.
