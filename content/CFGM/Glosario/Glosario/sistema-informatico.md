# Sistema Informático
Un sistema es un conjunto de cosas que, relacionadas entre sí ordenadamente, contribuyen a un determinado objeto. Un sistema informático es aquel que permite almacenar información.

Se compone de tres partes principales:
- _Hardware_: componentes electrónicos (parte física) que engloban todas las piezas que componen el ordenador, como el procesador o las memorias.
- _Software_: parte virtual que incluye tanto el sistema operativo como las aplicaciones que se utilizan.
- _Usuarios_: se engloba tanto a los usuarios del sistema como a los que lo crean y mantienen.

Los sistemas informáticos pueden clasificarse con base en:
- _Su uso_:
    - Sistemas de uso específico
    - Sistemas de uso general
- _El funcionamiento del procesador_:
    - MIMD
    - SIMD
    - SISD
    - MISD
- _El tipo de computadora_:
    - Estaciones de trabajo
    - Macrocomputadoras
    - Minicomputadoras
    - Supercomputadoras
    - Terminales ligeros
