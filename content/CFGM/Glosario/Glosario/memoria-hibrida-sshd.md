# Memoria Híbrida SSHD
Las unidades SSHD (Solid State Hybrid Drive) combinan la tecnología de platos magnéticos de un [[Disco Duro]] tradicional con la velocidad de la [[Memoria Flash]]. Este sistema utiliza la parte de estado sólido como un búfer para mejorar la velocidad de acceso a los datos y agilizar el arranque del sistema. Entre sus ventajas destacan un menor consumo de energía, mayor autonomía en portátiles y una fiabilidad superior para tareas de edición de vídeo y aplicaciones multimedia.
