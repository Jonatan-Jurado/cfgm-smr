# Informe de Resolución de Incidencia
Documento técnico final que se emite para cerrar formalmente el expediente de una avería. En este informe se debe detallar de manera precisa el procedimiento técnico seguido, las piezas sustituidas (si las hubiera) y la forma definitiva en la que se ha solucionado el problema.
