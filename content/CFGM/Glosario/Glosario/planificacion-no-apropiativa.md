# Planificación no apropiativa

Es un modelo de planificación en el que, una vez que [[El Sistema operativo]]|el Sistema operativo asigna el procesador a un [[Proceso]], este mantiene el control del [[Recurso]] hasta que finaliza su ejecución o se bloquea voluntariamente. No se le puede retirar el procesador de forma forzosa, lo que simplifica la programación pero puede causar esperas ineficientes.
