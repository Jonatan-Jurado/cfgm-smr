# Sistema de almacenamiento de datos de alta velocidad
Almacenan datos en la memoria principal en lugar de en discos, lo que permite un acceso más rápido a los datos y un procesamiento en tiempo real.
Son especialmente útiles para aplicaciones que requieren un rendimiento muy rápido, como:
- _Comercio de alta frecuencia_
- _Análisis de riesgos financieros_
- _Detección de anomalías_
Algunos ejemplos incluyen:
- _Apache Ignite_
- _SAP HANA_
- _MemSQL_
