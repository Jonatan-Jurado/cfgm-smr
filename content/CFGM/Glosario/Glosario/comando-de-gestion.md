# Comando de gestión

Conjunto de instrucciones de consola utilizadas para manipular elementos del sistema. Para ficheros, destacan `touch` (creación de archivos vacíos), `cat` o `more` (visualización de contenido de texto por pantalla), `cp` (duplicación), `mv` (traslado o cambio de nombre) y `rm` (borrado definitivo). Estos comandos permiten una administración precisa del [[Sistema de archivos]] sin necesidad de [[Interfaz]] gráfica.
