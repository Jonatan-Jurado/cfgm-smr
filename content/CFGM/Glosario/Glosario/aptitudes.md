# Aptitudes
Características que pueden condicionar la conducta de una persona y que, además, le permiten llevar a cabo una tarea determinada. Algunas tienen una base hereditaria, pero muchas se adquieren y desarrollan con el aprendizaje. Son un aspecto a autoanalizar dentro del perfil personal para facilitar la elección adecuada de un trabajo.
