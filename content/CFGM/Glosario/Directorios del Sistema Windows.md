# Directorios del Sistema Windows
El [[Sistema Operativo]] organiza sus archivos críticos en rutas específicas:
*   **\Boot**: Archivos necesarios para el arranque del sistema.
*   **\Archivos de programas**: Ubicación por defecto de las aplicaciones instaladas.
*   **\ProgramData**: Carpeta oculta para datos de programas compartidos por todos los usuarios.
*   **\PerfLogs**: Almacena registros (logs) de rendimiento y aplicaciones.
*   **\Usuarios**: Contiene los perfiles y datos personales de cada [[Usuario]] del sistema.
