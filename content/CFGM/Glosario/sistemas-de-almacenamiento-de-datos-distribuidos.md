# Sistemas de almacenamiento de datos distribuidos
Sistemas que distribuyen los datos a través de múltiples nodos en un clúster.
- _Propósito_: proporcionar alta disponibilidad y escalabilidad horizontal.
- _Utilidad_: especialmente útiles para aplicaciones que requieren almacenamiento y procesamiento de datos a gran escala, como el análisis de big data y las aplicaciones en la nube.
- _Ejemplos_: Apache Hadoop, Apache Spark y Google Cloud Bigtable.
