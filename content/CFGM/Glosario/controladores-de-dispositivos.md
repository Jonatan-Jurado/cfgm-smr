# Controladores de Dispositivos
Programas informáticos específicos ([[Drivers]]) que permiten al [[Sistema Operativo]] interactuar con el [[Hardware]]. Actúan como una interfaz de traducción que abstrae las particularidades técnicas de cada componente para que el [[Software]] pueda utilizar sus funciones de manera estandarizada.
