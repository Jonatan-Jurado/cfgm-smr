# DVD
Un dispositivo óptico con las mismas dimensiones que un CD, pero con una capacidad de almacenamiento mucho mayor. Esta mayor capacidad se logra al utilizar un láser con una menor longitud de onda en comparación con el CD.
Tipos de configuración para mayor capacidad:
- _Doble capa_: Estos dispositivos incluyen una doble capa que permite leer los datos a dos niveles.
- _Doble cara_: Son elementos que están grabados en ambas caras del disco.
