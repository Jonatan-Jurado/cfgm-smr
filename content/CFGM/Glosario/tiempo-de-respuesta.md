# Tiempo de respuesta

Es el intervalo temporal que transcurre desde que un [[Usuario]] o [[Proceso]] realiza una solicitud o petición al sistema hasta que este ofrece el primer resultado o respuesta. Es un parámetro crítico para determinar el grado de satisfacción del Usuario.
