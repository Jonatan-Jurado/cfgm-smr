# Macrocomputadora

[[Sistema informático]] de gran tamaño y potencia diseñado para el procesamiento de volúmenes masivos de datos. Son utilizados principalmente por grandes corporaciones y organismos gubernamentales para tareas críticas como el procesamiento de transacciones bancarias, estadísticas censales o gestión de bases de datos empresariales.
