# Sistema preinstalado con partición de recuperación
Un tipo de sistema que incorpora un software diseñado por Microsoft para realizar la instalación del sistema operativo Windows y los drivers necesarios de forma automática. Su objetivo es agilizar el proceso de instalación, especialmente para un gran número de equipos, y ayudar a prevenir la distribución de copias no autorizadas. Se implementa mediante una imagen (copia) del sistema que se almacena en una de las particiones del disco.
