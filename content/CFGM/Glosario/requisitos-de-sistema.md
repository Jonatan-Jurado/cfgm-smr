# Requisitos de Sistema
Son las especificaciones de [[Hardware]] necesarias para la correcta instalación y funcionamiento de un [[Sistema Operativo]] o [[Software]]. Se dividen en Requisitos Mínimos, que son las condiciones obligatorias para que el sistema pueda arrancar, y Requisitos Recomendados, que garantizan un rendimiento fluido y una experiencia de usuario óptima.
