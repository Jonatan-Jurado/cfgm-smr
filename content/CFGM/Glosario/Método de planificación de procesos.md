# Método de planificación de procesos
Procedimientos utilizados para gestionar y asignar recursos del procesador a los diferentes procesos. Se clasifican en:
- _No apropiativos_: Una vez asignado el procesador a un proceso, no se le puede quitar.
- _Apropiativos_: Una vez asignado el procesador a un proceso, se le puede retirar.
