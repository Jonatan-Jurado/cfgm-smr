# Micronúcleo
Tipo de núcleo que se encarga de recoger las funciones más básicas del sistema operativo. Si se desea añadir funcionalidades, se debe hacer de forma modular.

- _Ventajas_: seguridad y portabilidad.
- _Desventajas_: mayor tiempo en la respuesta de las llamadas y una peor comunicación entre el hardware y sus controladores.
