# Transacción
Una transacción es un conjunto de operaciones que generan o modifican información que se encuentra almacenada en el sistema.

Cuando se realizan operaciones con dinero, las transacciones se tienen que realizar de forma atómica. Esto significa que hay dos opciones: o se realizan todas las operaciones o no se realiza ninguna.
