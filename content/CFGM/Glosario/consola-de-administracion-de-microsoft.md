# Consola de administración de Microsoft

Herramienta de gestión avanzada del sistema que se ejecuta mediante el comando "mmc". Permite integrar diferentes complementos (snap-ins) para la administración del equipo, como la gestión de "Usuarios y grupos locales". Es una interfaz modular utilizada para configurar aspectos técnicos que no están disponibles de forma directa en los menús básicos de usuario.
