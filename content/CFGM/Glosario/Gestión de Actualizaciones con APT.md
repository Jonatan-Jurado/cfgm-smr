# Gestión de Actualizaciones con APT
El sistema de gestión de paquetes avanzado ([[APT]]) permite mantener el [[Software]] actualizado y corregir fallos de seguridad. Los comandos principales son `sudo APT-get update`, que descarga la información de las versiones más recientes, y `sudo APT-get dist-upgrade`, que instala las actualizaciones disponibles tanto para las aplicaciones como para el núcleo del sistema.
