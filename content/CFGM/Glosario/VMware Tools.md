# VMware Tools
Una aplicación proporcionada por VMWare que se recomienda instalar dentro de la máquina virtual después de la instalación del sistema operativo invitado. Se instala seleccionando la opción "Install/Upgrade VMWare Tools" con el botón derecho del ratón.

Estas herramientas tienen dos funciones básicas:
- _Instalar los drivers necesarios_: para el uso de la máquina virtual (ej. ratón o red).
- _Mejorar la gestión de los recursos_: de la máquina virtual para aumentar la fluidez.
