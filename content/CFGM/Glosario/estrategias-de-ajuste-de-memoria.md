# Estrategias de Ajuste de Memoria
Son algoritmos utilizados por el gestor de memoria para decidir en qué hueco disponible se debe colocar un [[Proceso]]:
*   **Primer ajuste:** Se asigna el primer hueco encontrado que sea lo suficientemente grande.
*   **Siguiente ajuste:** Similar al primer ajuste, pero comienza la búsqueda desde la última asignación realizada.
*   **Mejor ajuste:** Se busca y asigna el hueco más pequeño que pueda albergar el Proceso para minimizar el desperdicio.
*   **Peor ajuste:** Se asigna el hueco más grande disponible.
