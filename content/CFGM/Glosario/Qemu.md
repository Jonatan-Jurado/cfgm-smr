# Qemu
Software libre con el que se pueden virtualizar casi todos los sistemas operativos, permitiendo instalaciones tanto de 32 como de 64 bits. Es capaz de emular una máquina de forma completa, incluyendo el procesador y los periféricos.

Carece de interfaz gráfica, aunque es posible utilizar un software adicional para comunicarse con Qemu si se hace desde un sistema operativo Windows. Los sistemas operativos que puede virtualizar son Linux, Solaris, Microsoft Windows, DOS y BSD.
