# Comandos de Gestión de Ficheros
[[Operaciones]] básicas para la administración de archivos mediante consola:
* **fsutil**: Permite, entre otras funciones, crear un [[Archivo]] indicando un tamaño específico.
* **type**: Se utiliza para visualizar el contenido de archivos de texto directamente en el símbolo del sistema.
* **copy**: Realiza el duplicado de un fichero hacia un destino indicado.
* **del / erase**: Comandos equivalentes utilizados para la eliminación de archivos.
