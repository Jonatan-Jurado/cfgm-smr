# Accesibilidad en el Sistema Operativo
Conjunto de funcionalidades y ajustes de [[Software]] diseñados para adaptar el [[Entorno de Trabajo]] a personas con necesidades especiales o discapacidades. Incluye herramientas como el narrador de pantalla para personas con problemas visuales, lupas, y configuraciones especiales para el teclado y el ratón que facilitan la interacción con el [[Hardware]].
