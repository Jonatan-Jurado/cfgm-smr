# Ranura del microprocesador

Variante de conector para [[CPU]] que permite la instalación del procesador de forma vertical mediante una tarjeta de circuito impreso. A diferencia del [[Zócalo]] (socket), este formato se asemeja a una [[Ranura de expansión]] convencional.
