# Instalación de software
Proceso de añadir un nuevo programa al ordenador. Para ello, es necesario tener el archivo ejecutable.

Procedimiento:
- Se puede obtener el archivo ejecutable de un dispositivo de almacenamiento externo (como un disco óptico o una memoria USB) o mediante su descarga de internet. Este archivo suele tener una extensión .exe en Windows.
- Una vez abierto el ejecutable, se deben seguir todos los pasos de configuración hasta finalizar el proceso.
- Después de la instalación, se puede comprobar que el software ha sido instalado en el Panel de Control, en el apartado de "Programas y características".
