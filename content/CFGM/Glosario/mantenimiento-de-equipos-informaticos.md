# Mantenimiento de Equipos Informáticos
El mantenimiento de un ordenador consiste en la realización de todas las tareas necesarias para que el equipo siga funcionando con normalidad y sus componentes trabajen al máximo nivel durante el mayor tiempo posible.

Se distinguen dos tipos principales de acciones de mantenimiento:
-   _Acciones o técnicas preventivas_: Se realizan antes de que ocurra una avería, con el objetivo de alargar la vida útil de los componentes y evitar riesgos.
-   _Acciones o técnicas correctivas_: Se implementan una vez que ha ocurrido un incidente o avería en el ordenador, para solucionar el problema.
