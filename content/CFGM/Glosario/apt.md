# APT

Es el sistema de gestión de paquetes avanzado creado originalmente para la distribución Debian y utilizado ampliamente en derivados como Ubuntu. Permite la administración de [[Software]] mediante la terminal utilizando comandos específicos: `apt install` para instalar aplicaciones, `apt remove` para desinstalarlas y el comando base `apt` para la descarga y gestión de los repositorios.
