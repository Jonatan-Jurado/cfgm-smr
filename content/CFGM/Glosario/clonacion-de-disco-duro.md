# Clonación de Disco Duro
Proceso de realizar una copia exacta de un disco duro, incluyendo todos sus datos, programas y configuración.
- _Propósito_: Se utiliza frecuentemente para restauraciones masivas, replicando un sistema operativo, datos, configuraciones y programas instalados en múltiples equipos con características idénticas.
- _Software necesario_: Para llevar a cabo la clonación se requiere software específico, como Clonezilla o Gparted.
