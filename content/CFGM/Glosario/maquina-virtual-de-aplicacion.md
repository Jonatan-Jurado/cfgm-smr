# Máquina Virtual de Aplicación
Es un tipo de [[Máquina Virtual]] que se crea específicamente cuando se lanza una aplicación y se cierra automáticamente cuando esta finaliza. Durante su ejecución, utiliza los recursos del [[Sistema Anfitrión]] para funcionar. Su objetivo principal es proporcionar un entorno de ejecución independiente del [[Sistema Operativo]] subyacente, permitiendo que las aplicaciones sean multiplataforma.
