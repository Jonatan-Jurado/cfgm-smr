# Consumibles de impresión
Elementos que se agotan con el uso normal de la impresora, principalmente cartuchos de tinta o tóner. El [[Mantenimiento Correctivo]] básico incluye la sustitución de estos componentes siguiendo el manual del fabricante y el mantenimiento de un stock de reserva para minimizar el [[Tiempo de Inactividad]] del equipo.
