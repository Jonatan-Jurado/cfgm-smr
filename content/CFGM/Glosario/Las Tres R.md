# Las Tres R
Conjunto de reglas fundamentales para la preservación del medio ambiente, especialmente relevantes para un técnico reparador informático.
- _Reducir_: Implica minimizar el uso de los recursos disponibles para realizar las tareas diarias. Un ejemplo es utilizar el papel de la impresora lo menos posible para disminuir el consumo de tóner y la contaminación.
- _Reutilizar_: Consiste en alargar la vida útil de un equipo informático el máximo tiempo posible. Esto reduce costes y la generación de basura tecnológica. También incluye la donación de equipos en desuso a asociaciones u organizaciones sin ánimo de lucro.
- _Reciclar_: Cuando un equipo informático debe ser sustituido y no puede ser reutilizado, se debe llevar a un punto de recogida autorizado para su tratamiento conforme a las normas medioambientales.
