# Bloque de Control del Proceso
Estructura donde el sistema operativo agrupa la información de todos los procesos del sistema, la cual incluye el identificador del proceso, estado, prioridad, recursos y permisos asignados. Se crea a la vez que el proceso y, cuando este es eliminado, se borra también toda la información.
