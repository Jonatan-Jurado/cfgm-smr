# Dispositivo de Almacenamiento
Los dispositivos de almacenamiento son componentes sensibles (especialmente los discos duros SATA con brazo lector electromagnético) que requieren cuidado con los golpes y movimientos bruscos.

Pasos para solucionar un problema derivado de estos dispositivos:
1.  Acceder a la BIOS de la placa base para verificar si se detecta su conexión.
2.  Ejecutar el software de detección (driver) para ver si necesita una actualización.
3.  Verificar si hay un suministro de energía insuficiente al dispositivo (en cuyo caso, el problema sería de otro elemento).
4.  Si todo lo anterior es correcto, la solución es la sustitución del disco de almacenamiento.
