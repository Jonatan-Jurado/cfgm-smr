# Big Data
Es la infraestructura necesaria para almacenar, procesar y analizar grandes volúmenes de datos de manera eficiente. Utiliza algoritmos y modelos matemáticos que permiten a las máquinas procesar grandes cantidades de datos y tomar decisiones basadas en dicha información. Su uso permite trabajar con IA y facilitar la toma de decisiones a nivel empresarial.

_Características principales_:
- _Gestión de gran cantidad de datos_: Es capaz de gestionar una gran cantidad de datos que, por su complejidad y dinamismo, sería imposible procesar con las bases de datos tradicionales.
- _Velocidad_: Se caracteriza por la velocidad a la que se generan, capturan y procesan los datos.
- _Diversidad de datos_: Los datos son de índole muy diversa y provienen de una gran variedad de fuentes, como transacciones comerciales, sensores, redes sociales o registros en línea.
- _Tipos de datos_: Los datos pueden ser estructurados (como datos en bases de datos relacionales), semiestructurados (como datos en formatos XML o JSON) o no estructurados (como texto, imágenes o vídeos).
