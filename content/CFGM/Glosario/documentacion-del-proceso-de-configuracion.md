# Documentación del proceso de configuración
Documentación que debe incluir una guía de la configuración del proceso de instalación y los parámetros de configuración recomendados para garantizar el correcto funcionamiento del sistema. Puede presentar diferentes escenarios de configuración basados en los intereses del usuario.
- _Instalación con configuración recomendada_: Se sigue la configuración sugerida para el sistema.
- _Instalación personalizada_: Se seleccionan manualmente los componentes que se desean instalar o no.
