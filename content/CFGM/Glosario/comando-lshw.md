# Comando lshw
Herramienta avanzada que extrae información detallada sobre la configuración del [[Hardware]] de la máquina (memoria, versión de [[Firmware]], configuración de [[Placa Base]], versión de [[CPU]], etc.). Puede usarse con el parámetro `-short` para obtener un resumen o con un paginador para ver el informe completo.
