# Comparación de perfiles disponible y exigible
El proceso de cotejar el perfil que una persona ya posee (disponible) con lo que se requiere para un título o puesto (exigible) con el fin de identificar las diferencias y las áreas que necesitan mejora. Esta comparación es fundamental para ver dónde están las brechas y qué se necesita desarrollar. Un ejemplo de estructura para esta comparación incluye los siguientes aspectos: _Aspecto_, _Perfil disponible_, _Perfil exigible_ y _Diferencia_.
