# Arquitectura del Sistema Operativo
Estructura en la que se organizan los sistemas operativos. Todos los sistemas operativos se estructuran en tres capas diferenciadas:
- _El kernel_
- _La capa intermedia_: En esta capa se encuentran muchas de las funciones del sistema operativo, como la comunicación con el hardware. Los programas se comunican con el hardware a través de esta capa.
- _La interfaz_

La arquitectura del sistema operativo depende del tipo de núcleo que tenga.
