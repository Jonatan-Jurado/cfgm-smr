# Tabla de Particiones GPT
Estándar moderno vinculado a interfaces de [[Firmware]] EFI ([[UEFI]]) que supera las limitaciones del sistema [[MBR]]. Permite la creación de hasta 128 particiones por disco y ofrece ventajas técnicas como menús gráficos de configuración, soporte para discos de mayor capacidad y mayores facilidades para la resolución de problemas y el acceso remoto.
