# Sistema de Codificación Unicode
El sistema de codificación Unicode es un sistema de 16 bits que se emplea en diversos sistemas de escritura, como el árabe, el griego o el japonés, entre otros. Se distingue por su mayor capacidad con respecto a otros sistemas de codificación.
