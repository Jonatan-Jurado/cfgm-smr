# Software Libre
Se refiere a programas que pueden ser copiados, modificados y utilizados sin coste alguno, con cualquier fin y redistribuidos. Se diferencia del software gratuito por las libertades que ofrece a sus usuarios.

Para ser considerado software libre, debe cumplir con las siguientes características:
- _Libertad para usarlo con cualquier propósito_: El usuario puede ejecutar el programa para cualquier fin.
- _Libertad para estudiar cómo funciona y modificarlo para adaptarlo a unas necesidades concretas_: Permite acceder al código fuente y realizar cambios.
- _Libertad para distribuir copias_: Se pueden compartir copias del software con otras personas.
- _Libertad para mejorarlo y publicar estas mejoras_: Los usuarios tienen la posibilidad de contribuir al desarrollo del software y compartir sus mejoras con la comunidad.
