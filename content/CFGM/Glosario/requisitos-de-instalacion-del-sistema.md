# Requisitos de Instalación del Sistema
Conjunto de especificaciones de [[Hardware]] y [[Software]]|Hardware y Software necesarias para que un [[Sistema Operativo]] funcione correctamente. Se dividen en:
- **Requisitos mínimos:** Condiciones obligatorias sin las cuales el sistema no puede instalarse o funcionar.
- **Requisitos recomendados:** Especificaciones óptimas que garantizan una experiencia de usuario fluida, estable y con un rendimiento adecuado de todas las funcionalidades del Software.
