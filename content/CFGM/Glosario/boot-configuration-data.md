# Boot Configuration Data
El BCD es el sistema de configuración de arranque utilizado en versiones modernas de [[Windows]] (Vista, 7, 10 y posteriores). Sustituye al antiguo [[Archivo]] Boot.ini y almacena la información necesaria para el inicio del sistema en un Archivo denominado bootmgr. Su gestión y consulta se realiza mediante la herramienta de línea de comandos BCDEDIT.
