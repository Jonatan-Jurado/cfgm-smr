# Interfaz gráfica de usuario (GUI)
Un tipo de interfaz de usuario que permite la interacción con el sistema operativo a través de elementos visuales como ventanas, iconos y punteros. En sistemas como Windows 10, ofrece diversas opciones de configuración para personalizarla.
