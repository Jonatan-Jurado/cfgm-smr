# Comando xcopy
Comando utilizado para copiar directorios.

- Para copiar también los subdirectorios que contiene, es necesario usar el modificador `/e` para indicar una copia recurrente.
- Requiere el nombre del directorio de origen y el nombre del directorio destino, separados por un espacio.
