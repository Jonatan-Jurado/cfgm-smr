# Comando de fichero

Instrucciones específicas para la manipulación y [[Gestión de Archivos]] individuales desde la consola. Incluyen:
- **fsutil**: Permite crear archivos definiendo un tamaño específico.
- **type**: Muestra el contenido de un fichero de texto directamente en el símbolo del sistema.
- **copy**: Duplica archivos indicando el origen y el destino.
- **move**: Cambia la ubicación física de un [[Archivo]] en el soporte de almacenamiento.
- **del / erase**: Comandos equivalentes utilizados para la eliminación de archivos del sistema.
