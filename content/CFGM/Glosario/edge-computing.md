# Edge computing
Las funciones del edge computing son similares a las del cloud computing, pero como el procesamiento se lleva a cabo mucho más cerca de la fuente de los datos se consigue una mayor velocidad y una reducción del tiempo de respuesta o latencia.

Relación con la nube:
- _Disminuye el tiempo de respuesta_: al enviar la información que debe ser procesada a centros de datos más cercanos, disminuye el tiempo de respuesta respecto a cloud computing.
- _Complementa la computación en la nube_: al proporcionar capacidades de procesamiento adicionales y más cercanas al usuario final.
- _La nube para grandes cantidades de datos_: la nube se utiliza para tareas que requieren grandes cantidades de datos y almacenamiento a largo plazo.
