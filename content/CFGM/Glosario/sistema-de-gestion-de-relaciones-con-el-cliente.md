# Sistema de gestión de relaciones con el cliente
Un sistema de gestión de relaciones con el cliente (CRM) ayuda a las empresas a gestionar las interacciones con los clientes, incluyendo el seguimiento de ventas, marketing y servicio al cliente.
Algunos ejemplos incluyen:
- _Salesforce_
- _HubSpot CRM_
- _Zoho CRM_
