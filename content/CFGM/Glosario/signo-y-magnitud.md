# Signo y magnitud
Método de representación numérica donde el bit que se encuentra más a la izquierda representa el signo (un 0 indica un número positivo, mientras que un 1 indica un número negativo). El resto de los bits representa el módulo del número.

Una de las desventajas de este método es la _doble representación del 0_ (por ejemplo, +0 y -0).

_Ejemplo (en una palabra de 8 bits)_:
- 12 se representa como 0 0001100
- -12 se representa como 1 0001100
