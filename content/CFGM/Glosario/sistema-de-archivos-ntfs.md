# Sistema de Archivos NTFS
Sistema de archivos que apareció junto con el sistema operativo Windows NT y es el que utiliza Windows 10. Incorpora robustez y seguridad respecto a los sistemas anteriores. Es el formato ideal para trabajar con discos duros internos y no con memorias USB.
_Ventajas_:
- _Mayor seguridad_: Ofrece la posibilidad de cifrar los archivos.
- _Copias de seguridad instantáneas_: Permite su creación.
